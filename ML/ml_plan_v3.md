## 1. v2 复盘：为什么要推倒重来

v2 不是纸上方案，它**真的跑完了**：`ML/outputs/` 下躺着 CNN / LSTM / Transformer / DeepONet 四个深度模型 ×5 折的权重、指标、预测和 8 张图。但跑出来的结果，恰恰证明这条路不划算。

> 【大白话·代理模型(Surrogate Model)】我们想做的东西叫「代理模型」：用一个**算得飞快的近似模型**，替代又慢又贵的 Abaqus 有限元仿真。类比：与其每次都跑一遍几小时的实验，不如训练出一个「经验公式 / 查询表」，输入参数立刻吐出结果。

### 1.1 四个实测铁证

| # | 实测结论 | 数据 |
|---|---------|------|
| 1 | **四个差异巨大的深度模型，成绩全挤在一起，且都没达标** | TAF_h 的 R² 分别 0.827 / 0.815 / 0.790 / 0.836，目标是 >0.90，全没到 |
| 2 | **地形对 TAF 的影响是地震波的 2.47 倍** | 跨地形标准差 0.129 vs 跨波标准差 0.052（全 174 工况实测）|
| 3 | **决定性一击：深度模型连「傻瓜基线」都打不过** | 「无视波、每个地形直接取 3 条波平均」MAE=**0.0469**；v2 最强的 DeepONet MAE=**0.0506**（更差）|
| 4 | **TAF_v 在物理上是半个伪命题** | v2 里 TAF_v 的 MAE 高达 0.30~0.51、RMSE 到 1.0（其它通道才 0.02~0.05）|

> 【大白话·R²、MAE】**R²（决定系数）**衡量「模型解释了数据多少变化」：1=完美，0=和「闭眼睛猜平均值」一样，还可能为负。**MAE（平均绝对误差）**就是「预测值和真实值平均差多少」，越小越好。

> 【为什么第 3 条最致命】那个「傻瓜基线」**连地震波长什么样都不看**，每个地形直接拿 3 条波的平均当答案，就已经 MAE=0.0469。而 v2 的深度模型**辛辛苦苦读完了 4000 步完整地震波**，结果 MAE=0.0506，反而更差。说明那套庞大的「时序编码器」**几乎没从波里学到任何有用的东西**——杀鸡用了牛刀，还没杀利索。

> 【大白话·为什么四个模型成绩一样 = 瓶颈不在模型】CNN、LSTM、Transformer、DeepONet 是四种原理完全不同的网络。如果模型能力是瓶颈，它们成绩应该拉开差距。结果它们挤在 0.79~0.84 —— 这是经典信号：**瓶颈在「问题怎么定义、数据有多少」，不在「用多深的网络」**。换更猛的模型是无效内卷。

### 1.2 病根诊断

- **你其实只有 3 条波，不是 525 个独立波形样本**。525 = 175 几何 × **3 波**。输入端真正的多样性只有「175 种地形 + 3 种波」。让一个吃 4000 步的重型网络去学「3 选 1」，它只会把波当成「这是 El_Centro / Loma / Northridge 中的哪一个」来死记，学不到可迁移的物理规律。
- **地形才是主角**（2.47 倍），而地形参数只有 3 个标量（h, i, angle），是个标准的**小特征表格回归**问题，根本用不着深度学习。
- **波是配角**（只占 ~0.05 的变化），而且这点影响完全来自「频谱形状」，用十几个物理特征就能概括，不必喂原始时序。

## 2. v3 问题定义

### 2.1 任务

**输入** = 地形几何（主信号） + 地震波的少量物理特征（配角） → **输出** = 沿地表的 4 条曲线。

```
┌───────────────────────────────────────────┐
│  输入（低维特征向量，不再是 4000 步原始波） │
│  ├─ 几何（主信号）: h, i, angle             │
│  └─ 波的物理特征（配角，约 10 个标量）:     │
│       Arias强度 / 持时 / 卓越周期 / 反应谱Sa(T)… │
└───────────────────┬───────────────────────┘
                    │  经典 ML（XGBoost / 高斯过程 GPR）
                    ▼
┌───────────────────────────────────────────┐
│  输出（统一 161 点, x/h ∈ [0,8]）          │
│  ├─ PGA_h(x/h)   水平峰值加速度曲线         │
│  ├─ PGA_v(x/h)   竖向峰值加速度曲线         │
│  ├─ TAF_h(x/h)   水平地形放大系数曲线       │
│  └─ TAF_v(x/h)   竖向地形放大系数曲线（病态，专项处理）│
└───────────────────────────────────────────┘
```

> 【大白话·TAF】**地形放大系数（Topographic Amplification Factor）** = 斜坡上某点的震动峰值 ÷ 同样地震下平地的峰值。>1 表示「地形把地震放大了」，是这个研究关心的核心量。
> ⚠️ 注意输出是 **161 点**（沿用代码 `config_v2.py` 的 `NUM_CURVE_POINTS=161`，x/h 从 0 到 8 步长 0.05）。v2 文档里写的「162」是笔误，以代码为准。

### 2.2 数据规模

| 维度 | 数量 |
|------|------|
| 几何工况 h×i×angle | 5×5×7 = **175 组**（实测 174 组 TAF 文件齐全）|
| 地震波 | **3 种**（El_Centro, Loma_Prieta, Northridge）|
| 总样本 | 174×3 ≈ **522 条曲线** |
| 每条曲线 | **161 点** × 4 通道 |

几何取值：h∈{10,50,100,200,400}、i∈{15,30,45,60,75}°、angle∈{0,5,10,15,20,25,30}°（规则网格）。

## 3. 关键洞察（全部real数据实测，可复现）

下面这些数字来自对 `E:\Abaqus\fuke-ALL` 全量原始数据的只读分析（脚本见附录 A，可用 `py -3` 重跑）。

### 3.1 地形 2.47 倍主导

| 变异来源 | 平均标准差 | 含义 |
|---------|-----------|------|
| 跨**波**（同地形，3 条波之间） | 0.052 | 换地震波带来的 TAF_h 波动 |
| 跨**地形**（同波，不同地形之间） | 0.129 | 换地形带来的 TAF_h 波动 |
| **比值（地形/波）** | **2.47** | **地形影响是波的 2.5 倍** |

TAF_h 实测范围 [0.495, 2.205]，均值 1.040。

### 3.2 傻瓜基线打败深度模型（v3 必须超过的下限）

| 方法 | TAF_h MAE（全区） | 峰值区(x/h≤2) | 远场区(x/h≥5) |
|------|------|------|------|
| 傻瓜基线：每地形取 3 波平均（**完全无视波**） | **0.0469** | 0.0480 | 0.0473 |
| v2 CNN | 0.0527 | — | — |
| v2 LSTM | 0.0544 | — | — |
| v2 Transformer | 0.0572 | — | — |
| v2 DeepONet（最强） | 0.0506 | — | — |

> 这张表就是 v3 的「成败线」：**v3 的主模型必须把 TAF_h（尤其峰值区）的 MAE 压到明显低于 0.0469，且 ≤ 0.0506**，否则就白干。
> 注意：0.0469 是「地形完全预测对、但放弃预测波」时的**理论下限**（剩下的全是 3 条波之间无法消除的散布）。一个好的几何模型应该轻松接近它；再借助波特征，在「见过的波」上还能更低。

### 3.3 TAF_v 物理病态

TAF_v = 坡面竖向PGA ÷ **平坦地表竖向PGA**。问题在于斜入射 SV 波下，平坦地表的竖向 PGA 本就接近 0：

- 实测 flat 竖向 |PGA_v|：最小值 = **0**，有 0.2% 的点 <1e-3，0.05% 的点 <1e-4。
- 这些近零点让「除法」结果爆炸 → v2 里 TAF_v 的 RMSE 飙到 1.0（`dataset_v2.py:108` 用 `clip(0,10)` 强行截断，就是在堵这个洞）。

**结论**：TAF_v **先稳健保留**（见第 7.4 节），自动检测并排除/标注近零点，单独评估，最后再决定是否进论文。

### 4.1 复用 v2 的成熟逻辑

目录结构、文件夹名解析、曲线插值到统一 161 点网格——这些 v2 已经做对了，**直接复用** `data/dataset_v2.py` 里的 `FOLDER_PATTERN` 和 `load_raw_dataset` 的「读 CSV → 按 x/h 排序 → `np.interp` 插值到 grid」那段。**唯一要换掉的是「波怎么处理」**：v2 是「重采样 + 补零到 4000 步」，v3 改成「算物理特征」。

原始数据结构（不变）：
```
E:\Abaqus\fuke-ALL\fuke-ALL-h{h}_i{i}_angle{angle}\
├── {wave}_scaled.txt              # 输入波: 两列 时间\t加速度
├── PGA-{wave}_scaled-slope.csv    # 坡面 PGA (列: x/h, PGA_h, PGA_v, ...)
├── PGA-{wave}_scaled-flat.csv     # 平地 PGA (算 TAF_v 用)
└── TAF-{wave}.csv                 # 现成 TAF_h (列: x/h, TAF_h)
```

### 4.2 波 → 物理特征（v3 的核心改动）

对每条输入波 `{wave}_scaled.txt`，算出约 10 个标量特征。

> 【⚠️ 实测重要发现】三条 scaled 波**都被统一调幅到 PGA = 0.3000**！所以「输入 PGA」是个**常数、零信息**特征，**必须剔除**。真正能区分三条波的，是**持时、频率成分、反应谱形状**。

实测的三条波特征（取自 `h100_i45_angle0` 文件夹）：

| 波 | dt | 点数 | PGA_in | Arias 强度 | 持时 D₅₋₉₅ | 卓越周期 Tp | 平均周期 Tm |
|----|----|----|--------|-----------|-----------|------------|------------|
| El_Centro | 0.02 | 1560 | 0.300 | 0.018 | **23.9 s** | 0.66 s | 0.54 s |
| Loma_Prieta | 0.01 | 3991 | 0.300 | 0.009 | 11.4 s | **1.60 s** | 0.64 s |
| Northridge | 0.01 | 3989 | 0.300 | 0.008 | 9.1 s | 0.81 s | 0.55 s |

5% 阻尼**反应谱** Sa(T)（同样能清晰区分三波，是最有信息量的特征）：

| Sa(T) | T=0.1 | T=0.2 | T=0.5 | T=1.0 | T=2.0 |
|------|------|------|------|------|------|
| El_Centro | 0.650 | 0.711 | **0.900** | 0.444 | 0.135 |
| Loma_Prieta | 0.684 | **1.097** | 0.565 | 0.303 | 0.239 |
| Northridge | 0.415 | 0.633 | 0.506 | 0.278 | 0.121 |

**v3 波特征清单（约 10 个）**：
1. `Arias` — Arias 强度
2. `D_5_95` — 有效持时
3. `Tp` — 卓越周期
4. `Tm` — 平均周期（Rathje 定义）
5. `Sa_0.1, Sa_0.2, Sa_0.5, Sa_1.0, Sa_2.0` — 5% 阻尼反应谱在 5 个代表周期的谱值
6.（可选）`PGV_in, PGD_in` — 由加速度积分得速度/位移峰值

> 【大白话·这些特征是啥】
> - **反应谱 Sa(T)**：想象一堆「自振周期各不相同的单摆」，让它们经历同一条地震波，记录每个单摆晃得最狠时的加速度，画成「周期 → 最大响应」曲线。它就是这条波的**「频谱指纹 / 音色」**，告诉你能量集中在快频还是慢频。这是地震工程里描述一条波最标准的方式。
> - **Arias 强度**：把整条波的能量从头加到尾的一个总量，衡量这条波**「总共多猛」**。
> - **卓越周期 Tp / 平均周期 Tm**：波的能量最集中在哪个周期 / 加权平均周期，反映波**「偏慢摇还是快抖」**。
> - **持时 D₅₋₉₅**：地震「主震阶段」持续多久（能量从累积 5% 到 95% 的时间）。
> 
> **为什么这套特征对 TAF 特别合理**：TAF 是个「放大系数」，本质是**频率相关**的现象（地形对不同频率的波放大程度不同）。三条波 PGA 都一样、区别全在频谱形状——而反应谱 Sa(T) 正是频谱形状的标准刻画。所以「波 → 反应谱特征 → TAF」这条物理链条是通的。

## 5. 建模方案

输出是 4 条 161 点的曲线。有两种把「预测一条曲线」变成「机器学习能做的事」的方式。

### 5.1 形式 A：逐点表格回归（简单，建议先做，v1 风格）

把 `x/h` 也当成一个**输入特征**，于是每个 `(工况, 波, x/h点)` 就是表格里的一行：

```
输入一行: [h, i, angle, Arias, D_5_95, Tp, Tm, Sa_0.1...Sa_2.0,  x/h]  → 输出: TAF_h 这一个点
```

- 行数 ≈ 174×3×161 ≈ **84,000 行**，直接喂 XGBoost。
- **优点**：直观、好实现、能查询任意 x/h。
- **缺点**：同一条曲线的 161 个点**不是相互独立**的，会让样本量「看起来很大」（虚高），所以**交叉验证必须按工况分组**（见 7.1）。

### 5.2 形式 B：POD/PCA 压缩曲线 + 回归（推荐，主力）

> 【大白话·PCA / POD（主成分分析 / 本征正交分解）】把一条 161 点的曲线，看成**「几种基本形状曲线的加权叠加」**。只保留最重要的十几种基本形状，就能几乎无损地拼出任意一条曲线。类比：用有限几块**乐高基础积木**就能拼出各种造型——你只要预测「每块积木用多少」，而不用逐点预测 161 个数。

流程：
1. 把训练集所有 TAF_h 曲线做 PCA，得到约 12~15 个「基本形状」（主成分）。
2. 模型不再预测 161 个点，改为预测**这 12~15 个主成分的系数**。
3. 预测完，反 PCA 还原成整条 161 点曲线（**自动光滑，不会锯齿**）。

**实测 POD 重构误差**（压成 N 个主成分再还原，MAE 多大）：

| 通道 | N=5 | N=8 | N=10 | N=15 | N=20 |
|------|-----|-----|------|------|------|
| TAF_h | 0.035 | 0.023 | 0.019 | **0.012** | 0.008 |
| PGA_h | 0.019 | 0.013 | 0.010 | 0.006 | 0.004 |

> 解读：TAF_h 压到 15 个主成分，重构 MAE 才 0.012——**远小于模型本身 ~0.05 的误差**。也就是说 POD 这一步**几乎不损失任何有用信息**，纯赚（把 161 维降到 15 维，问题从此良态）。
> （注：要 21 个主成分才覆盖 99% 方差，说明曲线有真实细节；但对照模型误差 0.05，15 个主成分已绰绰有余。）

### 5.3 用哪些模型

| 模型 | 角色 | 为什么 |
|------|------|--------|
| **XGBoost / LightGBM** | 主力之一 | 表格数据王者；**自带特征重要性**，能直接回答「波到底有没有用、哪个波特征最关键」 |
| **高斯过程 GPR** | 主力之一（推荐） | ~500 样本的经典代理模型；**自带预测不确定性** |
| 小型 MLP（全连接网络）| 可选对照 | 证明「神经网络也试过了」，但不作主力 |

> 【大白话·高斯过程 GPR 与「不确定性」】普通模型只给一个预测值；GPR 还会**告诉你它有多大把握**（给一个误差带 ±σ）。在见过的数据附近它很自信（带子窄），**离训练数据越远越不自信（带子自动变宽）**。类比：老司机在熟悉路段敢打包票，开到陌生路段会主动说「这段我也不太确定」。
> 这个特性对工程代理模型极其重要：当用户换一条**远离三条训练波**的新地震波时，GPR 会诚实地把不确定性放大，而不是一本正经地给个错答案。

## 6. 防止过拟合（小数据铁律）

> 【大白话·过拟合】模型把训练数据**死记硬背**下来了（连噪声都背），一换新数据就露馅。类比：只会背答案的学生，考原题满分，换道题就不会。522 个样本对模型来说很少，必须严防。

| 措施 | 具体做法 |
|------|---------|
| **特征少而精** | 几何 3 个 + 衍生几个 + 波特征 ~10 个，总共 ~15 个，不堆砌 |
| **POD 降维** | 输出从 161 维降到 ~15 维，大幅减少要学的参数 |
| **模型正则** | XGBoost 限制树深(max_depth≤4)、加 L2；GPR 选合适核函数与噪声项 |
| **分组交叉验证** | GroupKFold 按工况分组（见 7.1），杜绝「见过隔壁几乎一样的样本」刷高分 |
| **诚实外推测试** | 留一波 / 留一高度，看真本事（见 7.2）|
| **不确定性兜底** | GPR 的误差带，对没把握的预测自动示警 |

## 7. 评估与数据划分（重点，决定结论可不可信）

### 7.1 GroupKFold 按工况分组

> 【大白话·GroupKFold】做交叉验证时，把**同一工况的 3 条波绑在一起**，要么全进训练集、要么全进验证集。否则「训练集见过 h100_i45 的 El_Centro，验证集却放它的 Northridge」——两者几乎一样，模型会作弊式地考高分，骗自己。

沿用 v2 已经做对的 5 折 GroupKFold（按 `(h,i,angle)` 分组）。

### 7.2 诚实的外推测试

| 测试 | 做法 | 诚实标注 |
|------|------|---------|
| **留一波**（3 折）| 每次藏起一整条波，用另 2 条训练，预测被藏的波 | ⚠️ 只有 3 条波，相当于「用 2 个点画线再外推到第 3 点」，是**能力上限测试**，**不代表能泛化到任意新波**。结论必须如实写进论文。|
| **留一高度** | 藏起某个 h 值的全部工况，预测它 | 测「高度外推」能力 |
| **留一角度** | 藏起某个 angle | 测「角度外推」能力 |

### 7.3 分区指标（别被平坦区骗了）

TAF 曲线大部分区域 ≈ 1（远场平坦），只有坡面附近有峰。如果只看「全曲线 R²」，**大片平坦点会把 R² 刷得虚高，掩盖峰值预测得差**。所以：

- **峰值区**（x/h ∈ [0, 2]）和**远场区**（x/h > 5）的 R² / MAE **分开报告**。
- 保留 v2 已有的曲线级指标：峰值误差 `max(pred)-max(true)`、峰值位置误差 `argmax` 之差、DTW（曲线形状相似度）。

### 7.4 TAF_v 专项处理（稳健保留）

1. 在数据加载阶段，自动找出 flat 竖向 |PGA_v| < 阈值（如 1e-3）的 x/h 点，**标记为不可靠**。
2. 训练与评估 TAF_v 时**排除**这些点（不参与算 loss、不参与算指标）。
3. TAF_v 的指标**单独汇报**，不和其它三通道混在一起平均。
4. 在结果文档里明确写出「TAF_v 哪些 x/h 区段不可靠、为什么」，最后再决定是否进论文。

### 7.5 必跑的对照基线

新模型必须赢过这些，才算有价值：

| 基线 | 说明 |
|------|------|
| 全局均值 | 所有曲线一个平均值，R² 的零点 |
| per-geometry 均值 | 每地形取 3 波平均（= 0.0469 那个）|
| 规则网格线性插值 | 利用 175 是规则网格，直接对 (h,i,angle) 三维线性插值——这是「不用 ML」的真正下限 |

## 附录 A：诊断脚本（只读，可用 `py -3` 复现第 3 节数字）

> 用于核验「地形 2.47 倍」「傻瓜基线 0.0469」「TAF_v 近零比例」「POD 重构误差」「三波特征」等结论。纯读取，不写任何文件。

```python
import os, re, numpy as np, pandas as pd
root = r"E:\Abaqus\fuke-ALL"
pat = re.compile(r"fuke-ALL-h([\d\.]+)_i([\d\.]+)_angle([\d\.]+)")
waves = ["El_Centro", "Loma_Prieta", "Northridge"]
grid = np.linspace(0, 8, 161)                       # 统一 x/h 网格(161点)
folders = [f for f in os.listdir(root) if pat.match(f)]

# 1) 地形 vs 波 变异 + 傻瓜基线 MAE
TAFh = {}
for f in folders:
    m = pat.match(f); key = (float(m[1]), float(m[2]), float(m[3]))
    arr = []
    for w in waves:
        p = os.path.join(root, f, f"TAF-{w}.csv")
        if not os.path.exists(p): break
        d = pd.read_csv(p).sort_values("x/h")
        arr.append(np.interp(grid, d["x/h"], d["TAF_h"]))
    if len(arr) == 3: TAFh[key] = np.array(arr)
A = np.array(list(TAFh.values()))                   # (Ngeom, 3波, 161点)
print("跨波 std =", round(A.std(1).mean(), 4))       # 0.052
print("跨地形 std =", round(A.std(0).mean(), 4))     # 0.129
print("傻瓜基线 TAF_h MAE =",
      round(np.abs(A - A.mean(1, keepdims=True)).mean(), 4))  # 0.0469

# 2) POD 重构误差
X = A.reshape(-1, 161); mu = X.mean(0); U, S, Vt = np.linalg.svd(X - mu, full_matrices=False)
for n in [5, 10, 15]:
    Xr = (U[:, :n] * S[:n]) @ Vt[:n] + mu
    print(f"POD n={n} 重构MAE =", round(np.abs(X - Xr).mean(), 4))

# 3) 波物理特征(注意 PGA_in 三波都=0.300, 是常数, 要剔除)
g = 9.81
for w in waves:
    t, a = np.loadtxt(os.path.join(root, folders[0], f"{w}_scaled.txt")).T
    Ia = np.pi / (2*g) * np.trapezoid(a**2, t)      # numpy>=2.0 用 trapezoid
    c = np.cumsum(a**2); c /= c[-1]
    d595 = t[np.searchsorted(c, 0.95)] - t[np.searchsorted(c, 0.05)]
    print(w, "PGA_in=", round(np.abs(a).max(), 3), "Arias=", round(Ia, 3), "D5-95=", round(d595, 1))
```
