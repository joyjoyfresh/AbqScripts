## 0. 一页总览（整条流水线）

```
①设计工况(无量纲参数 + LHS采样)
   → ②自动算模型尺寸(宽/高/网格/时长)
      → ③Abaqus批量跑(夜间) + 只存地表全时程
         → ④后处理:地表时程 → FFT → 传递函数 H(f,x/h) + 工程量TAF/PGA
            → ⑤整理成训练表(无量纲特征 + POD压缩的H曲面)
               → ⑥机器学习(GPR/XGBoost + 残差学习 + SHAP + UQ)
                  → ⑦对比规范(B4) + 真实案例验证
```

每一步下面都给"做什么、用什么数、存到哪"。

## 1. 工况怎么设计

### 1.1 用无量纲参数，不用绝对量

这是全计划最关键的一条（对应 v2 的 C2）。**绝对坡高 h 换不了刻度就外推崩溃，无量纲量才能跨尺度推广。** 五个控制参数：

| 参数 | 含义 | 建议范围 | 为什么 |
|------|------|------|------|
| η = h/λ = h·fr/Vs | 坡高/波长比 | 0.1 ~ 2.0 | 地形放大第一控制量 |
| i | 坡角（坡面倾角，度） | 15, 30, 45 | 几何主因 |
| θ | SV 波入射角（度） | 0, 10, 20, 30 | **≤ 临界角 32.3°（ν=0.3），>30° 仅告警** |
| d/h | 覆盖层厚 / 坡高 | 0.2 ~ 2.0 | 地层共振控制量 |
| α = ρ₂Vs₂/ρ₁Vs₁ | 阻抗比（基岩/覆盖层） | 1.25 ~ 4.0 | 共振强弱，你现有 Vs=2000/1600≈1.25 是下限 |

附带派生量（后处理时算，不单独采样）：场地卓越周期 Ts = 4·Σ(dᵢ/Vsᵢ)，输入卓越周期 Tp = 1/fr，共振判据 Tp/Ts。

### 1.2 采样方法：拉丁超立方（LHS），不要全因子

全因子会爆炸（5 维各 5 档 = 3125 个，个人电脑跑不完）。做法：

1. **首批 120~180 个工况**：在 [η, i, θ, d/h, α] 五维空间做 LHS（或 Sobol 序列）采样。Python 用 `scipy.stats.qmc.LatinHypercube`。
2. **主动学习补点 50~100 个**（对应 C5）：首批训练 GPR 后，在候选空间算预测方差 σ²，挑 σ² 最大的 30~50 个点再跑，重复 2~3 轮。
3. 总计 **200~300 个工况**，约个人电脑 3~4 个月夜间产能。
4. 另留 **10~15 个工况跑真实地震波**，专门用于验证"H(f) 卷积合成 vs 直接 FEM"的闭环误差。
5. **把现有 174 个均质工况并入**：它们是 α→1（无阻抗差）、d/h→任意的退化子集，白赚训练样本。

### 1.3 命名规范

沿用你现有风格扩展：`fuke-ALL-h{h}_i{i}_angle{theta}_d{d}_a{alpha}`。每批夜间任务生成一个 `manifest.csv`（参数表 + 完成状态 + 校验和），方便断点续跑和追溯。

## 2. 模型尺寸怎么设计

**全部交给脚本按物理自动算，不要手填**（v8 的 `mesh_cfg['auto']=True` 已实现）。规则如下：

### 2.1 几何尺寸（单位 m）

| 量 | 取值规则 | 你现有默认 |
|------|------|------|
| 总长 total_L | ≥ 上平台 + 坡宽 + 下平台，两侧远场各留 ≥ 1 个波长 + 2~3 倍坡高 | 1800 |
| 上平台 left_flat | ≥ 5~8 倍坡高，让坡顶放大区充分发育、远场柱干净 | 1000 |
| 坡高差 H−h | 由 i 和 h 决定 | 200 |
| 基岩层厚 | ≥ 1 个基岩波长，承托人工边界 | 200 |
| 覆盖层厚 d | = d/h × h（由无量纲参数反算） | 由几何决定 |

**核心原则**：左右人工边界离坡脚/坡顶足够远（≥ 最长波长），否则边界反射污染坡体响应。波长 λ = Vs/fr，最软层最低频对应最长波长，按它留余量。

### 2.2 网格尺寸（最重要）

**按最软层 + 最高频率控制**（Kuhlemeyer-Lysmer 判据）：

```
Δl ≤ cs_min / (10 · f_max)，  其中 f_max = 2.5 · fc
```

例：软层 Vs=150 m/s、fc=4 Hz → f_max=10 Hz → Δl ≤ 150/(10×10) = 1.5 m。
单元类型 **CPE4R**（4 节点平面应变缩减积分）。**参数设计第一步就要定"软层 Vs 下限 + 截止频率"**，否则网格量失控、单算例跑不动。

### 2.3 时间步与时长

- 时间步 dt：满足采样定理，脚本自动校验。
- 分析步时长：覆盖输入波持续 + **静默尾段 `tail_seconds=2~3 s`**（v8 已支持）——让坡体混响衰减干净，频域提取 H(f) 才不泄漏。这是频域路线的硬保障。

### 2.4 地震动输入：宽频脉冲（频域路线的关键）

线弹性下传递函数 H(f) 与输入波无关，所以**每个几何只需跑 1 次宽频脉冲**就能一次性提取整条 H(f, x/h) 曲面，数据效率比"每几何 × 3 条波"提高 3 倍。

- 主脉冲：Ricker 子波，中心频率 fc≈4 Hz（有效带宽 ~1~10 Hz）。
- **补一条 fc≈1.5~2 Hz 的 Ricker**，因为低频端（场地基频 ~0.44 Hz 附近）单条 4Hz 能量不足。两条合并保证 0.5~10 Hz 全覆盖。
- 入射角 θ 达到/超过 SV→P 临界角（32.3°）时 v8 直接拒绝建模（超临界非均匀波下解析分母失效）。

## 4. 数据怎么后处理

后处理脚本（建议 `Postprocess_H_v1.py`，单文件、普通 Python 即可跑，不进 Abaqus）。两条产出线：

### 4.1 工程量线（给 B4 对比 + 直观结果）

对每个地表点：取加速度时程峰值 = PGA；除以同高度一维自由场 PGA = **TAF**（地形放大系数）。整理成 TAF_h 曲线，横轴 x/h ∈ [0, 8]，统一插值到 **161 个点**（沿用 v3 网格）。

### 4.2 频域线（核心，对应 C1）

对每个地表点 x 和参考输入点：

```
H(f, x/h) = FFT(地表点加速度) / FFT(输入/远场参考)
```

得到传递函数曲面 H(f, x/h)（约 161 空间点 × ~100 频点）。要点：

1. **相干函数筛选**：输入谱接近零的频段 H 会发散，用相干函数 < 阈值的频点剔除，只保留 0.5~10 Hz 可靠带。
2. **一维理论对拍 QA**：远场列的 H 应与 `case_meta` 里的 `ff_theory`（Thomson-Haskell 传递矩阵解）逐频吻合 ±5%，超差则该工况标记存疑、排查阻尼标定/边界污染。
3. **三波互验（用现有数据）**：若旧 ODB 还在，3 条波各反演一个 H，线弹性下三者应一致，其离散度 = 数值噪声的免费估计。

### 4.3 整理成训练表

最终落一张表，每行一个"几何工况 × 频点"或"几何工况"（取决于目标形式）：

```
特征(无量纲) | η, i, θ, d/h, α, Tp/Ts ...   目标 | H(f, x/h) 曲面 或 TAF_h 曲线
```

## 5. 机器学习怎么用这些数据

升级脚本 `train_v4.py`（大改动开新版，v3 流程整体复用）。

### 5.1 特征矩阵 X（无量纲）

`[η, i, θ, d/h, α, Tp/Ts]`，约 6~10 维，仍在 GPR/XGBoost 舒适区。**关键**：把 v3 的绝对量 h 换成 η = h·fr/Vs，留一高度的 R² 就能从负值（h=10→-6.8, h=400→0.02）转正。

### 5.2 目标 Y 与降维

- **主目标**：传递函数曲面 H(f, x/h)。曲面太大，用 **二维 POD（对矩阵做 SVD）压缩**，预计 20~40 个模态够用（v3 经验：161 维曲线 15 个主成分重构 MAE 0.012）。先画奇异值衰减曲线定模态数。
- 工程派生目标 TAF_h / Sa比：由预测的 H(f) 卷积任意输入波后在时域算，**自动对任意波成立**（虚拟传感器）。

### 5.3 数据划分：GroupKFold（防泄漏）

按几何工况分组做 5 折，确保同一地形的所有样本同进同出训练/测试，否则会数据泄漏、虚高。**绝不用随机 CV**——这正是 Ju 等(2024) 高估外推的根源。额外做留一波 / 留一几何外推测试，作为诚实的泛化证据。

### 5.4 模型

- **GPR（主力）**：RBF 核 + WhiteKernel，自带不确定性 σ。`MultiOutputRegressor` 预测多个 POD 系数 → 逆 POD 还原曲面。
- **XGBoost（次优 + 可解释）**：提供特征重要性，配 SHAP。
- 训练成本 CPU 秒级，不需要 GPU。

### 5.5 残差学习（多层上线后，对应 C3）

不要让 ML 直接学总放大，做物理分解，只学小残差：

```
目标 = log[ H_FEM ÷ (H_1D × H_topo) ]
   H_1D   = 一维层状理论解（毫秒级可算，免费）
   H_topo = 均质坡地结果（v3 已有，免费）
   残差   = 耦合项，量级小、平缓，小样本就能学好
```

残差显著偏离 1 的参数区，就是"规范把地形系数和场地系数简单相乘"出错的区域 —— 直接的科学/工程产出。

### 5.6 可解释性 + 不确定性 + 适用域（对应 C4）

- **SHAP**：对 XGBoost 用 TreeSHAP，输出每个无量纲特征的贡献度和交互效应（重点看 η×α 耦合）。
- **UQ 校准**：检验 GPR 预测区间的名义覆盖率 vs 实际覆盖率（可靠性图）。
- **适用域判别器**：任意新输入算"可信/外推预警"标签（GPR σ 阈值 + 训练集凸包距离），强制在输出里显示。

## 6. 验证与对比（收尾）

1. **B4 规范基线**（`baseline_codes_v1.py`，纯解析式、半天）：复现 Bouckovalas-Papadimitriou(2005)、GB 50011 地形增大系数、Eurocode 8 ST，在同工况上算 R²/RMSE/MAE，证明 ML 比现行规范准。
2. **均质退化回归**：layers=[] 跑一个旧 v3 几何，对拍 v3 曲线，MAE 应 < 网格误差。
3. **文献复现**：复现 Shen 2025 图 15（层状岩坡耦合放大），曲线对上。
4. **真实地震案例**（2~3 个，详见 v2 第八部分）：汶川 / 雅典 Adames / Aigion，喂真实参数 → 预测放大 → 对比震后调查，附适用域标签。

## 7. 最小可行清单（先做这 5 件，立刻能动手）

1. **写 `baseline_codes_v1.py`**：在现有 174 工况上算 B4 规范基线，补进论文①基线表。（半天，零计算）
2. **核查旧 ODB 是否还在**：在，则写地表时程提取脚本；不在，挑 10~20 个几何重跑。（1 周）
3. **定参数底线**：软层 Vs 下限 + 截止频率（决定网格和产能），再开 LHS 采样。
4. **写 `Postprocess_H_v1.py`**：10~20 个几何概念验证，确认 H(f) × 真实波频谱合成 TAF vs 直接 FEM 闭环误差 < 5%。（1~2 周）
5. 概念验证通过 → 全量 LHS 工况夜间批跑 → 升级 `train_v4.py`（特征无量纲化 + H 曲面 POD + GroupKFold）。
