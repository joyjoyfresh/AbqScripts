## 1. 项目概况

- **模型**：Abaqus 二维平面应变、层状岩质边坡地震波动响应。方法 = **斜入射 SV 波等效节点力 + 黏弹性人工边界（VAB）**；成层自由场由**频域 Thomson-Haskell 引擎**给出；土体非线性用**等效线性（EQL）**。
- **课题主线（最终定位）**：**软土场地考虑土体非线性的地震响应放大**（这是导师/答辩看重、且对标论文未覆盖的新内容）。
- **对标论文**：Shen 等 (2025)《The combined amplification effects of topography and stratigraphy of layered rock slopes…》，用 SPECFEM2D（**纯线性弹性 + Q 黏弹性阻尼**）。

## 2. 本会话已得出的核心结论（很重要，别丢）

1. **有限元方法本身是对的**：远场 FE 逐频 = 一维解析理论 **< 1%**（每个工况 case_meta 自动对拍 halfspace_err/single_layer_err≈1e-16）。地形机制也对（均质坡纯地形因子 1.47）。
2. **追不上论文 7.6 的真正原因 = 线性下的 2D 面波俘获方法差异**（等效力/VAB/CPE4R vs SPECFEM 谱元/Bielak/Stacey），**不是数值没做够**（CPE8R 仅 +3.6%、网格 4→2→1m 已收敛、尾段无影响），**也不是没考虑本构/滞回**（论文也是线性！加非线性只会让放大更低、离 7.6 更远）。本方法天花板：瞬态 ~2、稳态 ~3.5（持续正弦实测）。论文 7.6 可能含坡顶尖角局部数值尖峰，且**软层工况从未做过独立方法互验**。
3. **模态测试证明软楔 2D 共振模存在**（4 个局部模态 2.9–3.9Hz），即"模型表示不了共振"被证伪——只是瞬态激不满 + 模态密度高、能量分散。
4. **课题主结果（非线性强度扫描）**：弱震≈线性、强震被抑制（0.8g 时坡顶降到线性的 70%）。**新发现**：非线性把远场（1D）压得比坡顶更狠，**地形/2D 因子随强度上升（1.18→1.60）**——强震下一维共振被阻尼掉、地形相对贡献更突出。
5. **EQL 阻尼曲线已修正**：旧线性近似 `ξ=ξmin+k(1−G/Gmax)` 在中低应变过阻尼约 2 倍；已换成 **Masing 滞回阻尼 × Darendeli 修正(b=0.6) + 最小阻尼**，与 Darendeli(2001) 逐点吻合。
6. **本构/滞回的定位**：属于**非线性课题**（精修强震段、证 2D 机理），**不是用来追论文 7.6 的**。EQL 是等效线性、非真滞回；真非线性需滞回本构（Masing UMAT / 边界面 / 运动硬化近似），EQL 在 γ>~0.1–0.3% 起与真 NL 分叉。

## 6. 技术备注

- **运行方式**：批处理 `python Autorun_*.py [工作目录]`（用户的 python 会自动把用 mdb 的脚本转交 `abaqus cae noGUI=`）；独立 Abaqus 脚本直接 `abaqus cae noGUI=脚本.py`。
- **工作目录约定**：结果常放 `C:\Abaqus\<名字>`；批处理 main() 接受 argv[1] 作根目录。
- **报告读 case_meta + TAF csv**：远场=x<200 均值，坡顶峰=坡顶±窗口内 TAF_h 最大；EQL 结果在 `meta['eql']['layers']['surface']`(Vs0/Vs/GG/geff/xi)。
- **修改大文件注意**：曾遇到 bash 写大 .py 注入空字节/挂载读取截断；以文件工具(Read/Edit)为准，bash 读到截断属挂载同步延迟、非真损坏。
- **EQL 口径**：mode='1d' 软层整体均匀软化(标准稳)；'2d_element' 逐单元(重型，需 Abaqus 实测)。曲线在 `_eql_mod_damp`。
