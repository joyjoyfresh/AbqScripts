## 2 建模优化清单（v2→v3）

按代码文件命名规则：功能新增属大改，新建 `Modeling/Hybrid/slope_frame_ssi_full_v3.py`，v2 保留。

### 2.1 P0 必改（正确性，先于一切批量）

1. **重力两步法**：动力步之前插入 Static 通用步施加自重，分两级：
   - Level A（默认）：仅结构 + 基础自重（土体不加重力），VAB 弹簧承静载。锚点：柱底轴力 N≈Σ楼层质量·g/柱数（默认 5 层 4 柱 ≈613kN），静沉降量级合理。
   - Level B（列 P2）：全模型 geostatic（土自重 + 侧压系数），涉及静-动边界切换，风险高，单独试验不阻塞主线。
   - 涉及位置：`build_models`（建步处插静力步）、等效力/边界幅值曲线整体时移一个静力步长。
2. **crest_offset 参数化**（step4 前提）：`tssi_cfg` 增 `'crest_offset_B'`（M/B 倍数，0=右缘贴坡肩）；`add_frame_on_crest` 中 `x_off = left_flat - fw - crest_offset_B*fw`；数值写入 tssi_meta.json；注入机制已通，无需改 `_load_case_config`。
3. **输出补全**：楼层历史输出增 U2/A2；BASE 柱脚增 U2（摇摆角 θ=(u2_前柱−u2_后柱)/B）；底层柱单元增 SF1/SF2/SM1 历史输出（基底剪力直取，与 Σm·a 互校）；nonlinear 时对 Frame 单元集加场输出 DAMAGET/DAMAGEC/PEEQ，整体能量 ALLPD/ALLIE/ETOTAL。ODB 体积沿用 surface_only 思路：场输出仅限 Frame 单元集 + 降频。
4. **框架瑞利阻尼锚定模态**：f1、f2 由结构周期自动计算（f1≈0.8/T1，f2≈5/T1 覆盖前三阶），替换固定 1~5Hz；T1 先用 0.1N 估算，step1 单体实测后注入修正。
5. **frame_material_cfg 纳入注入**：`_load_case_config` 的 TSSI 注入元组由三段扩为四段。
6. **T_fixed 去硬编码**：`write_tssi_meta` 中 `T_fixed_step1=0.5` 改为按层数 0.1N 估算或实测值注入（8 层结构下 0.5s 是错的）。

### 2.2 P1 应改（物理保真，随 step3/step4 一起）

7. **基础板选项**：新增 `foundation_cfg`（接口见附录），`'footing'` 模式在柱脚下加条形基础（B21 加强梁或实体条带）+ 基础下土体网格局部加密；柱脚与基础刚接（tieRotations=ON），基础-土 Tie；为接触升级留口。
8. **接触场景（强震专用）**：Tie → 硬接触 + 库仑摩擦（μ≈0.4~0.6）允许提离滑移，考察摇摆/滑移占比；仅批 C 强震代表工况启用。
9. **收敛降级链固化**：CDP viscosity 5e-4→2e-3 → 初始增量减半 → 自动增量放松 → 转 Explicit（决策点 D1：架构级改动，斜入射等效节点力施加方式需重核，不默认做）。
10. **nlgeom 评估**：step3 代表工况开 ON 对比一例，层间位移角>1% 时批量开启。

### 2.3 P2 可选（支撑 §9 拓展篇）

11. 结构参数化生成（给定目标 T1 反算截面/质量）；12. 全模型 geostatic；13. 坡顶多结构 SSSI；14. 3D 切片；15. 桩基/埋深基础。

## 3 参数考察设计

### 3.1 无量纲参数框架（与第 4 章 TAF 框架衔接）

| 类 | 参数 | 取值档 | 说明 |
|---|---|---|---|
| 地形 | 坡角 i | 30 / 45(主) / 60° | 复用第 4 章结论选代表值 |
| 地形 | 坡高 hs | 50m(主) / 200m(对照) | 结构-地形尺度比 B/hs=0.36 / 0.09 两个域，见下 |
| 地层 | 分层 | 均质岩坡；上软下硬（表层 Vs=400） | 成层放大与地形放大的联合效应 |
| 输入 | 入射角 | 0 / 15(主) / 30° | 斜入射摇摆效应（Q5） |
| 输入 | Ricker fc | 按共振设计 fc·T1∈{0.5, 1, 2}，另含场地 f_site 点 | 保证覆盖增震/减震两侧（Q2） |
| 输入 | 强度 | PGA 0.05g(弹性域) / 0.2g / 0.4g | IDA-lite 三档（Q4） |
| 输入 | 真实记录 | 附录 A 波库选 3 条 | 校核 Ricker 结论的波形敏感性 |
| 结构 | 层数 N | 3 / 5 / 8（T1≈0.3/0.5/0.8s） | 频率比 T1/T_site 三档跨 <1 / ≈1 / >1 |
| 结构-场地 | 刚度比 s=H_b/(Vs·T1) | 由上组合派生记录 | s>0.1 为 SSI 显著性经典判据 |
| 位置 | M/B | 0 / 0.5 / 1 / 2 / 3 / 5 | hs=50m 时补 M/hs=2、3 两点验证远场收敛 |

**尺度选择依据**：默认 hs=200m 时框架（B=18m、高 15m）相对地形极小，基底输入近似均匀、M/B≤5（90m=0.45hs）仍全程处于坡肩强梯度带内，扫不出衰减；hs=50m 时结构与地形梯度同阶、也更贴近工程坡地建筑。故 **M/T 扫描主打 hs=50m，hs=200m 作大坡对照**。M 双口径记录（M/B 结构尺度、M/hs 地形尺度），检验 H3 的统一衰减律。

### 3.2 三胞胎工况法（每组参数三个模型，SSI 效应可分离的前提）

1. **freefield**：tssi_cfg.enable=False，出 TAF 与坡顶运动（CREST_REF 的 A1/A2）；
2. **fixed**：框架单体，基底 AccelerationBC=freefield 坡顶运动（脚本自动提取生成，杜绝手工换算）；
3. **ssi**：全耦合模型。

同几何同波下 freefield 可被不同结构/位置共用，摊薄成本。这是论文 5.3 去耦对比法在坡顶的推广（step2b-2）。

### 3.3 工况预算（隐式单模型 5~30min 估，非线性 ×1.5）

| 批 | 内容 | 模型数≈ | 机时≈ | 服务对象 |
|---|---|---|---|---|
| A 机理链条 | 1 几何 × 2 地层 × 3 波 × 3 场景（弹性） | 20 | 5h | Q1/Q2，论文 5.3/5.4 |
| B M/T 扫描 | 6 位置 × 3 结构 × 2 波 ×(ssi+fixed)+共用 freefield | 75 | 19h | Q3，论文 5.6 |
| C 非线性 IDA-lite | 3 PGA × 2 结构 × 2 位置 × 2 波（CDP）+ 弹性对照 | 36 | 15h | Q4，论文 5.5 |
| D 地形扩展 | (2 坡角 + 1 坡高 + 2 入射角) × 代表组合 | 25 | 8h | Q5 + 规律外推 |
| 合计 | | ≈156 | ≈47h（约 6 个通宵批） | |

## 4 考察指标与数据管线

### 4.1 指标定义

- **场地侧**：坡顶 TAF、传递函数 H(f)、坡面空间分布（复用第 4 章管线与 `Postprocess_All_surface_v2`）。
- **结构侧**：顶层加速度放大 β_top；最大层间位移角 IDR_max 及沿高剖面；基底剪力系数 V/W（柱底 SF 直取 + Σm·a 互校）；周期延长 T_ssi/T_fixed（动力响应 FFT 反推，注意近共振时读到受迫频率的陷阱——交接文档已踩过）；基础摇摆角 θ；滞回耗能占比 ALLPD/ALLIE；损伤沿高分布（DAMAGET/C）与塑性铰出现次序。
- **耦合机理**：可乘性残差 R=β_total/(TAF×β_fixed)−1（Q1 核心量）；增减震比 ssi/fixed（Q2）；运动 vs 惯性相互作用分离——基础输入运动与自由场之差为运动项，ssi 与 fixed 之差为惯性项主导。

### 4.2 数据入库

每工况一行 CSV（全部无量纲参数 + 全部指标），`Collect_All_results_v3` 汇总。该表直接作为第 6 章 ML 的 TSSI 数据集（特征=参数，标签=β_top/IDR/θ），支撑论文 6.6 的模型升级——TSSI 批量数据与 ML 章节形成闭环。

## 附：v3 接口草案（顶部配置，注释风格遵仓库约定）

```python
tssi_cfg = {
    'enable': True,            #! TSSI 总开关
    'scene': 'ssi',            #! 三胞胎场景 'ssi'=全耦合 / 'freefield'=纯坡地 / 'fixed'=框架单体+坡顶自由场输入
    'crest_offset_B': 0.0,     #! 距坡肩距离 M/B（0=右缘贴坡肩，step4 扫描参数）
    'gravity': 'structure',    #! 重力级别 'off'=现状 / 'structure'=Level A 仅结构自重 / 'full'=Level B 全模型(P2)
    'nonlinear': True,         #! CDP 混凝土+钢筋开关（沿用 v2）
    'history_freq': 1,         # 历史输出采样频率（沿用 v2）
}
foundation_cfg = {
    'type': 'tie',             #! 'tie'=柱脚点绑定(v2 现状) / 'footing'=条形基础板+局部加密
    'width': 20.0,             # 基础板宽（m，≥框架宽 18m）
    'thickness': 0.8,          # 基础板厚（m）
    'contact': False,          #! True=硬接触+库仑摩擦可提离（强震批 C 专用）
    'mu': 0.5,                 # 土-基础摩擦系数
```
