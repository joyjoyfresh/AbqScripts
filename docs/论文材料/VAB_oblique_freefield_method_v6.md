# 斜入射 SV 波 + 粘弹性人工边界（VAB）自由场等效节点力方法说明（v6）

> 对应脚本：`VAB_oblique_TAF_double_v6.py`
> 自检脚本：`freefield_selfcheck_v1.py`（纯 Python 可跑，不依赖 Abaqus）
> 适用对象：二维平面应变、基岩 + 覆盖层两层、斜坡地形、斜入射 SV 波的 TAF 研究

本文档记录方法原理、关键物理约定与验证结论，便于论文方法部分引用，以及后续代码维护。

---

## 1. 方法总览

模型为**有限**土体，真实大地**无限**。直接截断会产生边界反射污染结果。采用**粘弹性人工边界（VAB，刘晶波等）**：

1. 在左/右/底三条边界的每个节点上施加**弹簧 + 阻尼器（接地）**，吸收散射波、抑制零频漂移；
2. 在边界节点上施加**等效节点力**，把"无斜坡、水平成层时该处本应有的地震运动"（即**自由场**）作为入射波场喂入。

单个边界节点的等效节点力采用标准格式：

```
F = K · u_ff + C · v̇_ff + A · (σ_ff · n)
```

- `K·u_ff`：弹簧力（自由场位移）
- `C·v̇_ff`：阻尼力（自由场速度）
- `A·(σ_ff·n)`：自由场面力，`A` 为节点影响长度（× 单位厚度），`n` 为该边界**外法向**
  - 左边界 `n=(-1,0)`、右边界 `n=(+1,0)`、底边界 `n=(0,-1)`

阻尼系数：法向 `ρ·cp`、切向 `ρ·cs`（标准取值）。

## 2. 自由场计算原理（核心）

### 2.1 物理图像：一根"土柱"的地震反应

自由场 = **远离斜坡处，从基岩底贯通到地表的一根土柱**在地震波作用下的反应。波从柱底入射、向上传播，在柱顶**自由面**反射，并在层界面之间多次反射、转换（SV↔P）。

实现：直接多波 Zoeppritz 界面解（基岩入射 SV + 界面反/透射 + 覆盖层自由面多次混响），见 `_propagator_matrix_freefield` / `_compute_freefield_at_node`。

### 2.2 为什么必须用"从底到顶"的几何

土柱有两个端点边界条件，缺一不可：

- **顶端（地表）= 自由面**：应力为零，是反射波的来源 → 必须知道顶在哪；
- **底端 = 入射波入口**：波从此进入 → 必须知道底在哪、传播相位累积多少。

柱内任一点运动 = 上行波 + 下行（反射）波叠加，依赖**整根柱子的几何**，无法孤立求单点。

### 2.3 厚度的物理意义：层共振

软覆盖层像共鸣腔，固有频率约 `f ≈ Vs / (4H)`（H 为软层厚度）：

- 软层**厚** → **低频**共振
- 软层**薄** → **高频**共振

地震波频率撞上共振频率即被强烈放大——即**场地放大效应**。**厚度直接决定放大哪个频率、放大多少**；厚度填错 = 共振算错 = 自由场算错。

## 3. 关键物理约定与已知近似

### 3.1 输入幅值约定（"2E" 自由面效应）—— 论文必须声明

代码把**输入加速度记录积分得到的速度，视为基底入射上行 SV 波的幅值 E**。

- 自由岩面运动 = **2E**（自由面位移反射系数 +1，入射 + 反射叠加），即**模型地表运动 ≈ 2×输入记录**，这是**正确物理**（free-surface effect / "2E" 露头约定），不是误差。
- 这是一个**约定**，论文应明确写明"输入 = 基底入射波 E"还是"输入 = 露头运动 2E"。本实现为前者。
- **对 TAF 无影响**：`TAF = PGA_slope / PGA_flat`，斜坡与平坦自由场模型用同一输入、线性分析，归一化常数在比值中**精确抵消**。仅当引用**绝对 PGA** 时需按 E / 2E 换算（若视记录为露头 2E，则入射应取 记录/2）。

### 3.2 底边覆盖层厚度按 x 取值（v6 修正）

斜坡使覆盖层左厚右薄。底边横跨厚区与薄区，**每个底节点应按其正上方柱子的真实厚度**取覆盖层厚度（坡顶侧厚、坡脚侧薄、坡面线性过渡），见 `_surface_y_at`。
v5 旧做法对所有底节点一刀切用最厚值，会使底边右段与右边界自由场不自洽（右下角点尤甚）。

### 3.3 速度基线校正（v6 修正）

加速度积分为速度时做基线校正：**去加速度零偏 + 速度线性去趋势**（`_integrate_acc_to_velocity`），避免低频漂移经 `位移 = 速度/(iω)` 被放大。

### 3.4 角点叠加是正确处理（非 bug）

左下/右下角点同属侧边界与底边界两个节点集，会分别计算等效力（面力 + 弹簧 + 阻尼）并**叠加**。这是 VAB 在角点的**标准正确处理**：角点形函数横跨两个边界单元，`∮(σ·n)·N dΓ` 本就应叠加两段（法向不同）贡献；Abaqus 中同节点多个集中力相加、多个接地弹簧并联相加。**不可折半**。

### 3.5 已知局限（仍为近似）

- 自由场假设**局部水平成层**，斜坡本身非水平成层，坡面附近"自由场"有固有模糊性；
- 材料为纯弹性（无 Q 衰减），靠数值阻尼 `MODERATE_DISSIPATION`；
- 弹簧刚度用固定 `R = ymax`、系数 0.5/0.25，属文献取值区间内的简化。

## 4. 验证结论（`freefield_selfcheck_v1.py` 实跑）

退化算例 = 均匀半空间（覆盖层 = 基岩）+ 自由面；另含两层对比算例。

| 判据 | 物理预期 | 实测 | 结论 |
|---|---|---|---|
| A1 垂直入射地表水平放大 | 2.0（自由面） | 2.0000 | ✅ |
| A2 垂直入射地表竖向/水平 | ≈0（SV 纯水平） | ~2e-12 | ✅ |
| A3 自由面 σ_yy、τ_xy | ≈0（自由面条件） | ~1e-17 | ✅ |
| 内部点 \|τ_xy\|/(ρ·cs·\|v\|) | O(1)（标度自洽） | ~2.6 | ✅ |
| B 斜入射 15° 自由面/有限 | ≈0 / 全有限 | ~1e-17 / True | ✅ |
| C 速度基线校正残余 | ≈0（朴素漂移 100%） | ~1e-16 | ✅ |
| D2 右下角厚度一致性 | 修正后=0（旧做法显著） | 0.0（旧 1.40） | ✅ |

**核心结论**：自由场引擎的"应力 σ 与位移/速度之间的绝对标度与符号"经退化自检证明**正确**（地表放大精确 2.0 + 自由面应力≈0 + 阻抗量级 O(1) 三者共同佐证），等效节点力三项处于同一量纲与相位约定下。

> 注：自检验证的是**自由场引擎本身**。三项叠加施加到 FE 模型能否复现自由场，最终建议用一次 Abaqus 算例确认——最干净的是跑 flat（坡度=0）模型，期望各点 PGA 处处相等、TAF≡1。
