## 2.1 引言

近场波动有限元模拟必须把无限大地基截断为有限计算域，并通过人工边界与波动输入方法把地震波"喂入"模型。对于均质半空间，斜入射SV波的自由场存在封闭解析解，等效节点力可以严格计算；但对于"基岩半空间+多层覆盖层"的成层场地，边界自由场不再有简单的解析表达，其计算精度直接决定了波动输入乃至整个数值模型的精度上限。本章首先给出弹性波动理论基础与均质半空间斜入射SV波自由场解析解；进而系统剖析工程中常用的时域射线叠加类自由场算法在成层场地下的误差机理；在此基础上建立基于频域全局矩阵精确自由场的粘弹性人工边界等效节点力输入方案，并通过多级交叉验证确认方法的正确性。本章建立的波动输入方法是后续各章数值模拟的共同基础。

## 2.2 弹性波动理论基础

### 2.2.1 弹性介质中的波动方程

均匀各向同性线弹性介质中，忽略体力时的运动方程（Navier方程）为

(λ+G)∇(∇·u) + G∇²u = ρ ∂²u/∂t² (2.1)

式中：u为位移向量；λ、G为Lamé常数（G即剪切模量）；ρ为介质密度。对位移场作Helmholtz分解，可将波动方程解耦为无旋的纵波（P波）方程与无散的横波（S波）方程，二者的传播速度分别为

c_p = √[(λ+2G)/ρ]， c_s = √(G/ρ) (2.2)

对于本文研究的二维平面应变问题，面内波场由P波与SV波两种体波构成，二者在自由表面与介质分界面上会发生波形转换与能量重新分配，这是坡地波场复杂性的根源。

### 2.2.2 平面波在界面上的反射与透射

平面波入射至两种介质的分界面时，需满足界面上位移连续与应力连续条件，由此产生反射波与透射波，且斜入射时伴随P-SV波形转换。各支波的传播方向由Snell定律确定：沿界面方向的水平慢度（视慢度）在全场守恒，

p = sinθ1/c1 = sinθ2/c2 = 常数 (2.3)

式中θ为各支波与界面法向的夹角，c为对应波速。反射系数与透射系数由界面连续条件构成的Zoeppritz型方程组求解，其数值与入射角、两侧介质的波速比及波阻抗比密切相关。需要特别指出的是，透反射系数存在"位移口径"与"应力（面力）口径"两种定义约定，二者数值不同，混用将导致系统性的幅值错误，这一点在第2.4节的误差分析中具有关键意义。

### 2.2.3 SV波在自由表面的反射与临界角

SV波以与竖直方向夹角α自下方入射至自由表面时，产生反射SV波（反射角α）与转换P波（反射角β），二者满足Snell定律sinβ=(c_p/c_s)sinα。由自由表面零应力条件可解得自由面反射系数A1（SV→SV）与转换系数A2（SV→P）：

A1 = [c_s²·sin2α·sin2β − c_p²·cos²2α] / [c_s²·sin2α·sin2β + c_p²·cos²2α] (2.4)

A2 = [2·c_p·c_s·sin2α·cos2α] / [c_s²·sin2α·sin2β + c_p²·cos²2α] (2.5)

垂直入射极限（α→0）时A1→−1、A2→0，地表水平位移幅值为入射幅值的2倍，即经典的自由面"2E效应"。当sinβ=(c_p/c_s)sinα=1时对应SV波的临界入射角θ_cr=arcsin(c_s/c_p)；泊松比ν=0.25时θ_cr≈35.3°，ν=0.30时θ_cr≈32.3°。入射角超过临界角后转换P波变为沿地表传播的非均匀波，上述实数角度关系失效，故本文的斜入射工况均控制在临界角以内。

## 2.3 均质半空间斜入射SV波自由场解析解

设SV波以入射角α自下方入射，入射波位移时程为u0(t)。半空间内任一点(x, y)的自由场为入射SV波、反射SV波与转换P波三支波的到时延迟叠加：

u_x(t) = u0(t−Δt1)cosα − A1·u0(t−Δt2)cosα + A2·u0(t−Δt3)sinβ (2.6)

u_y(t) = −u0(t−Δt1)sinα − A1·u0(t−Δt2)sinα − A2·u0(t−Δt3)cosβ (2.7)

式中Δt1、Δt2、Δt3分别为入射SV波、反射SV波、反射P波由参考波前传播至该点的几何走时。速度场由位移场求导得到，应力场由本构关系经各支波的波线方向导数给出，例如侧边界上的水平正应力为

σ_x = (G/c_s)·sin2α·(v_A − A1·v_B) + A2·[(λ+2G·sin²β)/c_p]·v_C (2.8)

式中v_A、v_B、v_C为三支波各自到时延迟后的速度时程。对均质半空间，式(2.6)~(2.8)是严格精确的，这也是大量文献验证算例均采用均质场地的原因。本文将其作为频域方法退化验证的基准解。

## 2.4 成层场地时域射线叠加法及其误差机理

### 2.4.1 射线叠加法的近似链条

对"基岩半空间上覆M层水平覆盖层"的成层场地，入射波在每个层间界面发生反射与透射并伴随SV-P转换，软覆盖层构成共鸣腔使波在层内无限次往返混响，多层之间还存在跨层耦合，自由场不再有封闭解析解。工程中常用的做法是将均质半空间解析解的思想推广为有限条波线的到时延迟叠加：

u^ff(t) = Σ_k A_k·u0(t−t_k) (2.9)

式中每条波线的幅值A_k由界面透反射系数与自由面系数的乘积链给出，走时t_k由逐层几何走时累加。为使波线数目有限，该类方法通常引入以下近似：①界面系数采用类SH波的法向阻抗近似，并将界面SV-P转换系数置零；②覆盖层内的无限次混响以截断几何级数代替（典型截断阶数N_r=3）；③多层情形下各层混响被当作彼此独立的腔分别叠加，忽略跨层耦合路径；④波线幅值按弹性介质计算，不含材料衰减。

### 2.4.2 误差机理逐项剖析

上述近似在均质半空间退化时全部消失，这解释了为什么该类方法在单层验证算例中表现"精确"、推广到多层后却系统性失准。本文将其误差来源归纳为六类：

（1）界面SV-P转换缺失。斜入射时每次界面透射/反射均伴随P转换波，置零意味着边界自由场缺失一族波至，导致竖向分量与应力分量系统性失真。垂直入射时该项误差为零。

（2）透反射系数口径错配。阻抗近似给出的系数实为应力（面力）比口径，而按位移连续与应力连续推导的位移口径透射系数应为T_ss=2Z1/(Z1+Z2)。将应力口径系数直接乘在位移/速度时程上会产生隐蔽的幅值错配：由于双程往返乘积恰好对称相等，腔内混响幅值"侥幸"正确，常规的单层共振校核难以发现问题；但单程透射幅值在波由硬介质进入软介质时被系统性低估。对本文典型三层柱（剪切波速2000→800→400 m/s），软表层内侧边界节点的直达波幅值最多可被低估至真值的约0.2倍量级。

（3）直达路径缺单程透射放大。入射直达波支以单位幅值进入各覆盖层，未乘逐界面的位移透射放大因子（硬→软透射时T_ss>1），与第（2）项同向，进一步压低覆盖层内边界节点的自由场幅值。

（4）多次波截断与双重计数。截断几何级数使高阶混响能量丢失，且部分实现中"标量等效反射系数"与"时域逐项叠加"两种口径并用，使各次波至的幅值分配混淆，结果随截断阶数漂移。

（5）跨层耦合缺失。多层柱中"表层→下覆层→再返回表层"的耦合混响路径被丢弃，当各界面阻抗比均较大时，该族路径携带的能量不可忽略，地表响应的共振峰位置与幅值均会偏离精确解。

（6）边界内外介质不一致。自由场按弹性介质计算，而有限元域内介质施加了瑞利阻尼，边界节点上"自由场假定的运动"与"有限元域内实际传播到该处的运动"在幅值与相位上系统性失配，弹簧-阻尼器会把这一失配当作"散射波"吸收，等效于在边界附近引入虚假的能量吸收或注入。

上述误差中，第（2）（3）（5）（6）项共同压低侧边界（尤其软表层段）的输入幅值与能量，使坡体响应整体偏弱；第（1）项额外扭曲斜入射工况的竖向分量。这是本文前期采用射线叠加输入的多层工况地形放大系数系统性偏小的输入侧成因，也是促成波动输入算法升级的直接动因。

## 2.5 频域全局矩阵精确自由场方法

### 2.5.1 基本思想

等效节点力所需的自由场本质上是一维问题：远离坡体处场地水平成层，自由场只取决于该边界节点所在的竖直成层柱。对水平成层介质中的平面波，频率域内存在精确解——这正是地震学中Thomson[127]-Haskell[128]传递矩阵与Knopoff[129]全局矩阵方法谱系所解决的经典问题[130]。本文按全局矩阵思路实现：不再追踪任何具体波线，而是在每个频率上一次性解出每层全部上、下行波幅，从根本上消除第2.4.2节的第（1）~（5）类误差；再以复模量、复密度计入与有限元域一致的瑞利阻尼，消除第（6）类误差。

### 2.5.2 波场表示

取x轴水平向右、y轴竖直向上，时间因子取e^(iωt)。斜入射由全场守恒的水平慢度刻画：

p = sinα0 / c_s(0) (2.10)

式中α0为基岩中SV波入射角，c_s(0)为基岩剪切波速。第m层内的位移场为上行P波、下行P波、上行SV波、下行SV波四类平面波的叠加：

u(m)(x,y,t) = Σ_w a_w(m)(ω)·d_w(m)·exp[iω(t − p·x − k_y,w·(y − y_ref,w))]，w∈{P_u, P_d, S_u, S_d} (2.11)

式中a_w(m)为各支波的复幅值（频域未知量）；d_w(m)为极化向量，与半空间解析解的约定严格一致；竖向慢度为

q_s(m) = √(1/c̃_s(m)² − p²)， q_p(m) = √(1/c̃_p(m)² − p²)， Im(q) ≤ 0 (2.12)

上行波取k_y=+q且以层底为参考深度，下行波取k_y=−q且以层顶为参考深度，保证一切相位因子在层内沿传播方向衰减，数值上无溢出风险，从而规避了Thomson-Haskell经典实现的高频溢出病态。各支波对应的应力分量由本构关系给出（∂_x→−iωp，∂_y→−iωk_y）。

### 2.5.3 全局矩阵方程组

设柱内有M个有限覆盖层（自下而上编号1,…,M），层0为基岩半空间。基岩中上行SV波幅值为已知输入（取单位幅值），未知量为基岩反射下行P波、下行SV波两支，加上每个有限层的四支波，共4M+2个。边界条件恰好给出同样数目的方程：自由表面处σ_yy=0、σ_xy=0共2条；每个层间界面处位移u_x、u_y与应力σ_yy、σ_xy连续共4M条。将波场表达式代入即得逐频线性方程组

A(ω)·x(ω) = b(ω) (2.13)

式中右端项b由已知入射波在基岩顶界面的场量贡献移项而得。该(4M+2)阶小型稠密方程组对全部频点批量直解，三层柱（M=2）仅为10阶。解出x(ω)后，柱内任意深度的位移、速度与全部应力分量随之精确确定——界面透反射、SV-P转换、任意阶多次波与跨层耦合全部隐含在方程组的解中，无需任何波线枚举与截断（图2.1(b)）。

### 2.5.4 阻尼一致化：复模量与复密度

有限元域内的介质满足含瑞利阻尼的运动方程，其频域形式等价于把每层材料替换为复密度与复模量：

ρ̃ = ρ(1 − i·α_R/ω)， G̃ = G(1 + iω·β_R)， λ̃ = λ(1 + iω·β_R) (2.14)

对应的频率相关阻尼比为

ξ(ω) = α_R/(2ω) + β_R·ω/2 (2.15)

式中α_R、β_R为瑞利阻尼系数。各层(α_R, β_R)取与有限元建模完全相同的换算流程（由品质因子换算阻尼比后双频点拟合，见第3.6节），代入波场表达式即得衰减一致的自由场。阻尼只是把实波速变为复波速，方程组结构不变，全部精确性得以保持。若自由场仍按弹性介质计算（旧方案假定），喂入边界的共振幅值将系统性偏离有限元域内实际可传播的幅值。

### 2.5.5 时域恢复与数值实现

输入加速度记录a_in(t)（约定为基岩中入射波幅值）经补零FFT得到入射位移谱U0(ω)=−a^_in(ω)/ω²。节点(x0, y0)处任一场量的频谱为"单位入射柱解×输入谱×水平传播相位"：

f̂(x0,y0,ω) = F(y0,ω)·U0(ω)·e^(−iωp·x0) (2.16)

经逆FFT即得时域自由场。数值实现中采取四项关键处理：①谱幅值掩码——仅对幅值超过最大谱值10⁻⁷倍的频点求解，既省算力又规避高频段大衰减指数的数值下溢；②补零防卷绕——FFT长度取原记录的4倍以上并取2的幂，保证多次波尾部不经循环卷积折返污染响应窗口；③局部参考相位——所有指数因子模不大于1，全局矩阵无高频溢出病态；④柱解缓存——同一地表高度的柱共享一次求解，单个工况的自由场计算耗时为秒量级。

## 2.6 粘弹性人工边界与等效节点力输入

### 2.6.1 粘弹性人工边界

本文在模型左、右、底三条截断边界的每个节点上布置接地的弹簧-阻尼器（粘弹性人工边界，VAB）[41]，同时吸收散射波并抑制低频整体漂移。对二维平面应变问题，节点法向与切向的弹簧刚度与阻尼系数取

k_N = α_N·(G/R)·A_l， c_N = ρ·c_p·A_l； k_T = α_T·(G/R)·A_l， c_T = ρ·c_s·A_l (2.17)

式中G、ρ、c_p、c_s为节点所在介质层的剪切模量、密度、纵波与剪切波速；A_l为节点影响长度；R为波源等效距离（实现中取模型高度）；法向与切向修正系数按二维标准取值α_N=0.5、α_T=0.25。需要强调的是，成层场地中侧向人工边界截面跨越不同材料层，式(2.17)中的介质参数必须按节点实际所在地层逐节点取材（实现细节见第3.7节），否则将在边界上产生非物理的伪反射。

### 2.6.2 等效节点力

人工边界本身只负责"吸收"，要把地震波输入模型，需在边界节点上施加等效节点力，使边界在自由场作用下精确再现入射波场：

F_B(t) = K·u^ff(t) + C·v^ff(t) + A_l·σ^ff(t)·n (2.18)

式中K、C为式(2.17)的弹簧/阻尼系数矩阵；u^ff、v^ff、σ^ff为该节点处自由场的位移、速度与应力张量；n为边界外法向。式(2.18)揭示了一个常被忽视的事实：等效节点力方法的输入精度完全受制于自由场的计算精度。有限元求解器在模型内部可以精确模拟任意复杂的反射、透射与波形转换，但如果喂入边界的自由场本身有误，模型内部的"精确求解"只是对一个错误输入的精确响应。本文以第2.5节的频域全局矩阵精确自由场替代射线叠加近似自由场组装式(2.18)，即从源头保证了波动输入的精度。

## 2.7 方法验证

方法正确性按"由简到繁、相互独立"的多级体系验证。

令覆盖层数M=0，全局矩阵退化为2阶（自由面两条件解基岩反射P波、SV波），其解应严格等于式(2.4)~(2.5)的A1、A2，边界节点的位移、速度与面力时程应逐点还原式(2.6)~(2.8)的解析解。验证结果表明（图2.2），SV波15°斜入射下底边界节点的水平速度与边界面力时程，频域全局矩阵解与解析解逐点重合。这一检验覆盖了波场表示、极化约定、应力系数与外法向符号的全部实现细节。

## 2.8 本章小结

本章从粘弹性人工边界等效节点力的基本格式出发，论证了"波动输入精度受制于自由场精度"这一核心命题，主要工作与结论如下：

（1）给出了均质半空间斜入射SV波自由场的解析解及SV波临界入射角的限制条件，作为后续方法验证的基准。

（2）系统剖析了时域射线叠加类波动输入方法推广至成层场地时的六类误差来源，指出其中透反射系数口径错配类误差因双程乘积对称性而在常规单层校核中不可见，是"单层验证通过、多层系统失准"这一现象的深层原因；对本文典型三层场地，软表层边界节点的直达波幅值最多可被低估至真值的约0.2倍。

（3）建立了频域全局矩阵精确自由场算法：以4M+2阶逐频线性方程组取代波线枚举，精确包含界面SV-P转换、任意阶层间多次波与跨层耦合；以复模量-复密度实现自由场衰减与有限元域瑞利阻尼的频率相关一致化；该方法不引入任何需要标定的离散化参数，单工况自由场计算耗时为秒量级。

（4）通过半空间解析退化、独立Thomson-Haskell递推对照、材料退化一致性与界面连续性等多级交叉验证，确认了方法实现的正确性。

需要说明的是，本章方法在算法层面继承了Thomson-Haskell/全局矩阵的经典框架，本文的贡献在于面向粘弹性边界等效输入的工程实现、衰减一致化处理，以及对既有时域射线类输入方案误差机理的系统揭示与量化。
