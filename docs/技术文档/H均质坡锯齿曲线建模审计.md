# H均质坡锯齿曲线建模审计

_审计日期：2026-07-26；对象：`Modeling/slope_frame_ssi_full_v2.py`、H1—H3 `run-001/run-002`结果与H正式入口。_

## 结论

本轮先检查建模脚本，不以新增一天级Abaqus试算代替调试。生产P–SV单柱求解器、边界积分、外法向应力和`Ku+Cv+Aσ`分量映射均未发现代数实现错误，但进一步审查识别出一个比“底边三种柱高怎么选”更根本的模型形式错误：旧`local_columns`把左侧上平台柱、右侧下平台柱和底边连续变高柱拼成所谓自由场，它们不是同一个二维波动方程解。等效节点力公式要求位移、速度和应力来自同一个背景自由场，仅做到角点数值连续并不够。

主脚本现新增`reference_field_mode`，H正式入口冻结为`global_upper`：左、右、底三条人工边界全部从同一个以上平台为自由面的平场解取值，实际坡面和下平台相对该背景场产生的反射、转换和散射只由有限元域计算一次。旧`local_columns`只保留用于历史复现，不再用于H正式数据。既有H `run-003`复制的是修复前脚本，仍不得启动；这次修复先由纯Python平面波闭合测试验证，后续再在新运行目录进行Abaqus预生产质量门。

## 阻尼配置问题与修复

H旧工况配置写有`constant_xi=0.03`，但主脚本一直把该参数限定为“有限土层统一阻尼”；H工况为`layers=[]`，所以实际均质材料没有采用3%阻尼。`run-001/run-002`的`case_meta.json`记录的实际值均为`Q=999、xi=0.0005005005`。这不是求解时随机失效，而是配置表达容易让人误读。

H均质坡承担“去除覆盖层后的基岩坡`H_topo`”角色，需与成层模型中的基岩材料保持一致，本轮不把它事后改成3%并制造新的基线。修复内容为：

- H正式入口显式写为`constant_xi=None、q_bedrock=999、bedrock_xi=None`，物理结果与旧H一致；
- 主脚本新增可选`bedrock_xi`，确需固定基岩阻尼时可显式设置；
- 日志和`case_meta.json`记录配置作用域及每层实际`Q/xi/alpha/beta`；
- 非法阻尼比和品质因子直接中止，不再静默进入材料定义。

因此，阻尼语义已经修复，但这项修复本身不会把旧H曲线变平滑。

## 为什么宽频曲线比旧射线法曲线起伏更多

对同一模型、几何和自由场引擎的既有数据计算二阶空间粗糙度，2 Hz、4 Hz、8 Hz Ricker分别约为`0.0018、0.0035、0.0079`，宽频多正弦为`0.0141`。频带越宽，多个频率成分在坡肩、坡面和坡脚形成的相干散射峰谷越密，PGA又取各空间点完整时程的绝对峰值，峰值发生时刻可在相邻位置切换，因此空间PGA曲线天然比单一Ricker结果更起伏。

把当前H结果仅用于诊断地限制到既有Ricker共同可靠上限约4.8 Hz后，水平曲线粗糙度由H1/H2/H3的`0.0209/0.0145/0.0136`降至`0.0038/0.0039/0.0035`。这说明大部分“锯齿感”来自宽频高频分量和峰值取法，而不是空间插值。该低通结果只能用于解释来源，不能替代原始0.5—10 Hz结果或被当成正式修图。

## 底边参考场根因与修复

当前`bottom_ymax_mode=local`在每个底边节点使用其正上方真实地表高度构造一维自由场柱。这样能保证左下角与上平台自由场一致、右下角与下平台自由场一致，并在坡面投影范围内连续过渡；但它也使底边输入随坡面高度变化，相当于参考场已经含有一部分与坡形相关的相位和幅值变化。

以H1代表参数`h=200 m、i=60°、θ=30°、side_clearance=1h`进行无Abaqus解析扫描：

| 底边柱高口径 | 水平底边自由场PGA范围 | 相对跨度 |
| --- | ---: | ---: |
| `local` | 1.767343—1.835842 | 3.762% |
| `upper` | 恒为1.835842 | 0 |
| `lower` | 恒为1.812046 | 0 |

上述时域PGA跨度只有`3.762%`，曾使问题看起来像“可接受的局部近似”。但PGA把不同频率和不同时刻的峰值折叠在一起，会严重掩盖频率逐点的不一致。对同一`H_lower=600 m、H_upper=800 m、Vs=2000 m/s`均质坡做垂直入射单频检查，旧局部柱在底边同一高程的水平自由场幅值跨度为：

| 频率 | `local_columns`底边幅值跨度/最大值 | `global_upper` |
| ---: | ---: | ---: |
| 0.5 Hz | 47.427% | 0 |
| 1.0 Hz | 61.803% | 0 |
| 2.0 Hz | 100.000% | 0 |
| 4.0 Hz | 100.000% | 0 |
| 8.0 Hz | 100.000% | 0 |
| 10.0 Hz | 100.000% | 0 |

垂直入射时，任一固定高程上的平面自由场应与`x`无关。旧口径却令柱顶高度成为`H(x)`，使底边场写成`F(y;H(x),f)`；在坡面投影区，其`x`导数额外包含`H'(x)∂F/∂H`，而脚本计算的应力仍来自各自一维柱，没有包含这部分空间导数。因此，旧位移场与旧应力场并非同一二维解，不能共同代入等效节点力公式。高频处恰好会在不同柱高上跨越多个驻波波节，足以直接制造密集的频率—空间起伏，这与既有宽频H曲线的锯齿增强现象一致。

修复后的`global_upper`具有三个明确性质：

1. 三条人工边界统一使用`F(y,f)exp(-iωpx)`，位移、速度与应力来自同一个背景解；
2. 背景场只包含上平台平场传播，不预含真实坡形，坡面散射不会在边界输入和有限元自由表面中重复计算；
3. `global_lower`不能用于当前单面坡，因为左边界存在高于下平台自由面的节点，脚本现会直接拒绝这种无物理意义的外推。

这不是为了让曲线“看起来更平”而选参数，而是按等效节点力波场分解的数学前提修复参考场。公开的抬升地形斜入射实现同样以单一参考自由面生成左、底、右三条边界的入射/反射波场，而不是逐`x`更换自由面；其自由场与散射场叠加为总场的推导可见[Cao等（2022）](https://doi.org/10.3390/sym14112244)。同时应保留适用范围：局部VAB自由场输入仍假定散射波能被人工边界充分吸收，高频和大角度地形散射可能需要总运动场输入或边界积分耦合，相关局限见[Wang等（2024）](https://doi.org/10.1016/j.soildyn.2024.108901)。所以`global_upper`关闭的是“拼接场不自洽”问题，不等于取消后续计算域收敛门。

另一个可能的干扰已经排除：H入口采用`phase_origin_x=center`，而左右侧净空是对称增加的。坡肩相对相位原点的位置恒为`0.5h-w_slope/2`，坡脚相对位置恒为`0.5h+w_slope/2`，均与`side_clearance`无关；纯Python回归对`0.1/1/4h`三档结果完全一致。因此`run-001/run-002`的差异不能归因于扩大域时偷偷改变了坡体处输入相位。
