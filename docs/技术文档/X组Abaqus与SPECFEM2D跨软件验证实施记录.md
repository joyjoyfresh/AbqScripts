## 2. 公共输入为何改为位移Ricker

SPECFEM2D v8.1.0的 `initialfield` 固定使用单位位移Ricker，并分别以一、二阶时间导数初始化速度和加速度。`SOURCE/factor` 对该初始场不生效。因此，原有标准加速度Ricker不能直接写成与SPECFEM2D内置波形相同。

本验证采用以下唯一公共定义：

1. 位移脉冲为4 Hz单位Ricker；
2. Abaqus输入为该位移脉冲的解析二阶导数；
3. 沿SV偏振方向的矢量峰值取 `0.1g=0.980665 m/s²`；
4. SPECFEM2D保持单位初始场，所有输出统一乘 `0.0010350222766`；
5. 不允许按测点、分量或时段再次调整幅值；
6. 公共时间为 `t_common=t_SPECFEM+0.3 s=t_Abaqus-0.3 s`。

生成的Abaqus加速度文件为：

`Wave/Impulse/Acceleration/ricker_displacement_derived_acceleration_4Hz_0p1g.txt`

文件共2001行，`dt=0.001 s`，峰时0.300 s，峰值绝对值0.980665 m/s²，SHA-256为：

`c09bef8643c0a63be2bd3b66d075453e4d18ef7ee5049f67ed39f27c85cb372f`

按加速度幅值谱不低于峰值5%的规则，有效频带为1.6972—11.0916 Hz。

## 3. 边界方案的实算决定

初始平面波以

`q=sin15°·x+cos15°·z`

定义传播法向坐标，初始峰值平面取 `q=50 m`，相位原点为 `(800.0, 458.570163) m`。P061覆盖层内初始包络为：

| 场量 | 覆盖层最大值/全局峰值 |
| --- | ---: |
| 位移 | 0.133% |
| 速度 | 0.374% |
| 加速度 | 0.617% |

三者均低于1%，说明初始非零波包仍位于基岩缓冲区。

但在假定100 m厚C-PML时，左侧和底部内边界的速度包络接近100%。同时，v8.1.0先把PML记忆变量置零，再写入非零初始平面波；自带旧Gmsh转换器使用的PML方向码也与当前读取器不一致。故正式X工况采用：

- 地表：自由边界；
- 左、右、底：Stacey吸收边界；
- 入射修正：左、右、底开启Bielak，顶部关闭；
- `PML_BOUNDARY_CONDITIONS=.false.`；
- `STACEY_ABSORBING_CONDITIONS=.true.`。

P061仍有一个不能隐瞒的边界：内置解析场按首个材料计算，侧边覆盖层不是真正的成层解析自由场。X002采用单进程、首单元为基岩并保存边界诊断点；正式结论必须限定在预先确定的边界安全时窗内。

### 6.1 覆盖层工况的入射判定

X002-S与X002-SR为覆盖层模型。P061内置解析入射场按首个材料（基岩）计算，覆盖层不是真正的成层解析自由场（见第3节）。因此，覆盖层底界面附近基岩测点的解析主峰时刻不适用：覆盖层（Vs=600 m/s）与基岩（Vs=2000 m/s）阻抗差异使界面透射波前发生延迟，R0003 `(500,500)` 位于界面下方60 m（小于基岩有效最短波长180.3 m），其主峰相对基岩解析值延迟约14 ms，Abaqus侧同样偏移约12 ms，属界面透射的物理效应而非求解缺陷。

`summarize_run` 的入射门控据此调整：覆盖层工况下，距覆盖层底界面小于基岩最短波长的基岩测点标记为 `within_cover_influence`，仅作辅助诊断，不参与正式入射门控；基岩深部测点R0001/R0002（距界面260 m，超出影响区）承担入射验证。X002-S与X002-SR的R0001/R0002主峰时刻误差绝对值均不超过0.003 s、偏振比误差不超过0.019、峰值相对误差不超过0.026，入射门控通过。X001-S（均质无覆盖层）三个测点全部参与门控，判定口径不变。

## 9. 谱比跨软件对比（G_h 型）

### 9.1 方法

为直接验证论文主研究量 $G_h(f,s)$（地表水平复频响）在两套求解器间的一致性，在已对齐的公共 801 点地表网格上计算傅里叶幅值谱及其 G_h 型谱比（地表谱 / 同侧远场自由场谱）。远场自由场代理取公共地表网格两端（$s \le s_{\min}+0.5$ 或 $s \ge s_{\max}-0.5$）的加速度时程均值，对两求解器采用完全相同的构造方式——即分母由各求解器自身远场数据独立生成，不共享或交叉引用。

频域分析参数：Tukey 窗（$\alpha=0.1$）抑制端部泄漏；零填充至 $N_{\text{FFT}}=8192$ 以提高频率分辨率（$\Delta f \approx 0.12$ Hz）；单边幅值谱按信号长度归一化。指标在 Ricker 有效激励带 1.7—10 Hz 计算为主，并在论文正式分析频带 0.5—10 Hz 补充报告。比较点位为坡顶（$s=0$）、坡面中部（$s=0.5$）和坡脚前方（$s=2$）。

| X002-A vs X002-SR | 0.572 | 0.723 | 0.683 |

X001（均质无覆盖层）的水平谱比 NRMSE 为 0.18—0.28，两求解器的 $G_h$ 型放大曲线高度一致。X002（成层覆盖层）的水平谱比 NRMSE 为 0.57—0.73，差异增大主要源于成层界面散射对 FEM 与 SEM 的空间离散敏感度不同；但 X002-S 标准网格与加密 SR 网格几乎一致（差值 <0.01），确认该差异为方法固有而非网格不足。

**竖向分量谱比 NRMSE 显著偏高（0.38—1.86）：** 竖向入射 SV 的竖向分量在远场代理中的幅值较小，除法运算将残余差异放大。竖向不是 $G_h$ 的定义分量，此处仅作辅助报告。

#### 主峰频率一致性

所有比较对的水平分量地表谱主峰频率偏差不超过 0.85 Hz（X002 坡面中 +0.85 Hz），多数点位 ≤0.12 Hz。这一精度远低于后续物理参数效应的主峰偏移量级（通常 >1 Hz），确认两求解器捕获了相同的共振特征。

### 9.3 低频段限制性声明

Ricker 脉冲的有效激励频带为 1.697—11.092 Hz（按峰值 5% 阈值判定）。因此 0.5—1.7 Hz 区间的谱比结果受信噪比约束，不作为正式门控依据。该低频段在完整研究链路中由一维解析传递函数（G0/G1b 继承资产）和宽频多正弦输入（G1b，0.5—12 Hz）覆盖，不在本 Ricker 脉冲验证范围内。

### 9.4 正式门控判据冻结说明（2026-08-02）
