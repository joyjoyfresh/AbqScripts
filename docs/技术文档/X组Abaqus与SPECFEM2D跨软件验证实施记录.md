## 2. 公共输入为何改为位移Ricker

SPECFEM2D v8.1.0的 `initialfield` 固定使用单位位移Ricker，并分别以一、二阶时间导数初始化速度和加速度。`SOURCE/factor` 对该初始场不生效。因此，原有标准加速度Ricker不能直接写成与SPECFEM2D内置波形相同。

本验证采用以下唯一公共定义：

1. 位移脉冲为4 Hz单位Ricker；
2. Abaqus输入为该位移脉冲的解析二阶导数；
3. 沿SV偏振方向的矢量峰值取 `0.1g=0.980665 m/s²`；
4. SPECFEM2D保持单位初始场，所有输出统一乘 `0.0010350222766`；
5. 不允许按测点、分量或时段再次调整幅值；
6. 公共时间为 `t_common=t_SPECFEM+0.3 s=t_Abaqus-0.3 s`。

生成的Abaqus加速度文件为：

`Wave/Impulse/Acceleration/ricker_displacement_derived_acceleration_4Hz_0p1g.txt`

文件共2001行，`dt=0.001 s`，峰时0.300 s，峰值绝对值0.980665 m/s²，SHA-256为：

`c09bef8643c0a63be2bd3b66d075453e4d18ef7ee5049f67ed39f27c85cb372f`

按加速度幅值谱不低于峰值5%的规则，有效频带为1.6972—11.0916 Hz。

## 3. 边界方案的实算决定

初始平面波以

`q=sin15°·x+cos15°·z`

定义传播法向坐标，初始峰值平面取 `q=50 m`，相位原点为 `(800.0, 458.570163) m`。P061覆盖层内初始包络为：

| 场量 | 覆盖层最大值/全局峰值 |
| --- | ---: |
| 位移 | 0.133% |
| 速度 | 0.374% |
| 加速度 | 0.617% |

三者均低于1%，说明初始非零波包仍位于基岩缓冲区。

但在假定100 m厚C-PML时，左侧和底部内边界的速度包络接近100%。同时，v8.1.0先把PML记忆变量置零，再写入非零初始平面波；自带旧Gmsh转换器使用的PML方向码也与当前读取器不一致。故正式X工况采用：

- 地表：自由边界；
- 左、右、底：Stacey吸收边界；
- 入射修正：左、右、底开启Bielak，顶部关闭；
- `PML_BOUNDARY_CONDITIONS=.false.`；
- `STACEY_ABSORBING_CONDITIONS=.true.`。

P061仍有一个不能隐瞒的边界：内置解析场按首个材料计算，侧边覆盖层不是真正的成层解析自由场。X002采用单进程、首单元为基岩并保存边界诊断点；正式结论必须限定在预先确定的边界安全时窗内。

### 8.3 分级评价说明

固定0—0.45 s诊断窗内，坡顶水平/竖向时程NRMSE为3.76%/7.33%；坡面中点和坡脚为11.24%—17.55%。随着地表相互作用和散射发展，差异明显增大。SPECFEM2D在坡面中点和坡脚的11.0916 Hz以上能量占比约14.6%—31.8%，而Abaqus低于0.1%；但只保留预定1.6972—11.0916 Hz频带后，六通道NRMSE仍为16.6%—30.3%，所以高频振荡只解释部分差异。

当前证据支持以下判断：

1. 公共输入、入射角、方向和时间基准已核对；三个基岩入射脉冲及0.30 s预定快照的结果相符；
2. 三项正式门控（PGA空间分布、PGA主峰位置、0.30 s早期全场快照）全部通过；
3. 逐点时程差异主要集中在地表散射和晚时段，对求解器的空间离散、时间推进及吸收边界实现敏感，属FEM与SEM的固有差异；
4. 正式总判定为 `formal_gates_met = true`，X002工况可按计划继续推进；
5. 论文表述可报告"在PGA空间分布和早期波场等工程关键指标上两套求解器一致，逐点散射时程差异为两种数值方法的预期偏差"。
