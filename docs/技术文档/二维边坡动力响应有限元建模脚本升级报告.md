# 二维斜坡 SV 波斜入射有限元建模脚本升级报告

本报告系统阐述了二维斜坡 SV 波斜入射有限元建模脚本从单层基岩版本（v2）升级为多层自适应版本（v8）的架构演进与核心算法改进。

---

## 一、总体架构演进

| 维度 | 单层基线版本（v2） | 多层升级版本（v8） |
|:---|:---|:---|
| 介质模型 | 均质弹性半空间（单一材料） | 基岩半空间 + 任意数有限层（1/2/3…层） |
| 自由场算法 | 弹性半空间解析公式 | 频域精确全局矩阵法（fd 引擎）+ 射线法（ray 引擎，对比回归用） |
| 材料阻尼 | 无 | Rayleigh 阻尼（双频拟合或仅刚度比例），支持逐层 Q 衰减 |
| 几何参数化 | 三段式固定比例（`h`, `3h`, `8h`） | 独立参数（`H_minus_h`, `h_over_H`, `left_flat`, `total_L`） |
| 网格策略 | 手动指定 + 频率波长取较小值 | Kuhlemeyer-Lysmer 自适应 + 手动上限 + 下限兜底 |
| 时间步控制 | 无 | dt 充分性校验 + 自动重采样 |
| 数据结构 | 裸标量散传 + numpy 列索引 | `namedtuple` 打包（`Material`, `Site`, `Geometry`, `BoundaryNode`, `FreeFieldCtx`） |
| 配置管理 | 内联字典 | `case_config.json` 注入覆盖 + 深合并 |
| 元数据输出 | 无 | `case_meta.json`（工况参数/TAF 分母/理论台阶/自检误差） |
| 表层几何 | 仅水平分层 | 水平分层 `horizontal` + 沿地形等厚铺设 `terrain` |
| 单元类型 | CPE4（硬编码） | CPE4 / CPE4R 可配置 |
| 平坦对照模型 | 必须运行 | `run_flat` 可配置（TAF 分母改为解析值，flat 仅作 QA） |
| ODB 输出 | 全场全时程 | 地表节点集全时程 + 整体场降频（`surface_only` 瘦身） |
| Py2/Py3 兼容 | 无特殊处理 | `_ensure_str` 递归 unicode→str + `io.open` 编码指定 |
| 代码规模 | ~1180 行 | ~2479 行（含完整注释） |

## 二、核心物理模型升级

### 2.1 从均质半空间到任意层状介质
- **基线版本**：整个模型域采用单一材料，自由场解析解直接使用半空间 SV 波入射的反射系数 \(A_1\)（SV→SV）和 \(A_2\)（SV→P）。
- **升级版本**：引入 `Site` = `(bedrock, layers, bedrock_thickness)` 结构化场地模型，支持全场均质基岩（自动退化为 v2 行为）、双层场地（基岩 + 覆盖层）以及多层场地（从上到下排列的任意数有限层）。每个层由 `Material` 命名元组定义，波速通过 `velocity_ratio` 指定以确保物理一致性。

### 2.2 频域精确自由场引擎（fd 引擎）
- **基线版本**：自由场计算基于半空间解析公式，对每个边界节点按三段延迟到时进行时域波形叠加。该公式仅适用于均质弹性半空间，无法处理层间界面的反射、透射与模式转换。
- **升级版本**：引入基于 **Thomson-Haskell 全局矩阵法**的频域精确自由场求解器：
  1. **物理完整性**：界面处 SV↔P 模式转换精确包含（不做阻抗近似）；任意阶多次波自然蕴含于全局矩阵求解中；瑞利阻尼以复模量/复密度在频域精确引入。
  2. **方程体系**：未知量为基岩反射波幅值与每层上/下行波的幅值（共 \(4M+2\) 个）；方程为顶部自由面剪切/法向应力为零加上各界面处位移和应力连续条件。
  3. **数值策略**：上行波参考层底、下行波参考层顶的相位约定以确保数值稳定；输入波 FFT 补零 4 倍防时域卷绕；仅求解幅值谱大于阈值的频点以节省算力。

### 2.3 射线法多层推广（ray 引擎）
作为 fd 引擎的对比回归路径，多层推广版包含了以下改动：
- **等效反射系数递归**：从自由面向下递归，将多层土合并为自由面的等效反射率。
- **腔体混响叠加**：将各有限层视为独立谐振腔，按几何级数截断阶数（最大3阶）枚举所有反弹路径。
- **穿层走时累加**：有限层侧边节点的到时改用逐段垂直走时累加。

### 2.4 材料阻尼体系
引入了完整的粘弹性阻尼框架，通过 `damping_cfg` 配置：
- 阻尼比由 \(Q\) 值确定（\(\xi = 1/(2Q)\)）。
- Rayleigh 系数双频拟合，使复模量阻尼与有限元 Rayleigh 阻尼严格同口径。
- **双控阻尼锚定**：瑞利阻尼拟合下限 \(f_1\) 取输入波主频因子与场地一维基频中的较小者，避免阻尼在共振点失真。

## 三、几何参数化重构

### 3.1 参数定义体系
由原有的硬编码比例尺寸解耦，采用无量纲参数化体系定义：
- 斜坡高度差 \(H - h\)
- 斜坡倾角 \(i\)
- 深度比 \(h/H\)
- 基岩层厚度 `bedrock_thickness`，使有限层的物理高程自洽确定。

### 3.2 表层几何模式
支持两种表层几何：
- **`horizontal`**（默认）：水平分层。
- **`terrain`**：表层沿地形等厚铺设，上下界跟随坡面地表起伏，切分线呈折线型分布。

## 四、网格与时间步自适应

### 4.1 网格尺寸自适应
基于 **Kuhlemeyer-Lysmer 准则**进行自适应网格剖分：
\[\Delta l_{\max} = \frac{c_{s,\min}}{10 \times f_{\max}}, \quad f_{\max} = 2.5 \times f_c\]
其中 \(c_{s,\min}\) 为最软层的剪切波速。网格尺寸受最小阈值（0.5m）兜底。

### 4.2 时间步校验与自动重采样
时间步 dt 需满足 `steps_per_period = (1/f_max)/dt >= 20`，不满足时自动通过 `np.interp` 对加速度记录进行升采样。

## 五、数据结构与工程化改进

### 5.1 命名元组打包
利用 `namedtuple` 对 `Material`、`Site`、`Geometry`、`BoundaryNode` 和 `FreeFieldCtx` 等配置量进行结构化封装。

### 5.2 场地分层带构造
`_build_stratigraphy` 将场地分层展开为“从下到上”的标称材料带列表（基岩带、覆盖层带、表层带），使建模切分、截面分配、边界弹簧选材和自由场柱构造四处口径严格一致。

### 5.3 配置注入机制
引入 `case_config.json` 覆盖合并机制。支持通过 `_deep_merge` 递归合并字典。在 Python 2.7 内置内核中，系统自动调用 `_ensure_str` 将 unicode 字符串转为 Abaqus 要求的 `str` 类型。

### 5.4 工况元数据输出
自动在工况文件夹下生成 `case_meta.json`，固化写入几何范围、逐层材料、无量纲频率、阻尼参数、TAF 归一化分母以及一维理论台阶 QA 锚点，供后处理端提取使用。

---

## 六、数值健壮性与质量保障
- **fd 引擎自检**：在每次建模前自动执行半空间退化和单层 SH 解析对拍自检（误差大于 \(10^{-3}\) 则中止建模），防止静默失效。
- **远场对拍 QA**：后处理段自动将 FE 上/下平台中位 TAF 值与 `ff_theory` 一维理论解对拍（限差 5% 闸门），自动拦截异常。
- **基线积分校正**：对加速度积分前先去除零频偏移，对积分后的速度用最小二乘拟合并扣除速度的线性趋势项，抑制低频漂移。
- **ODB 瘦身**：引入 `surface_only` 配置，仅对地表节点集输出 `(A, U)` 高频全时程，对整体场降频，大幅节约磁盘空间。
