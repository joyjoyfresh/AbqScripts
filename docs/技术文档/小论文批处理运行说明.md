# 小论文批处理运行说明

_更新日期：2026-08-02_

本文是小论文阶段的执行说明，内容包括：运行顺序、批处理命令、模型锁定、盲测、真实波重构和完成判据。研究范围以[主计划](../计划文档/毕业论文与小论文科研总计划.md)第 4 节为准。

## 一、先固定小论文口径

小论文最终回答四个问题：

1. 坡角、厚度比和波速比怎样改变复频响的幅值、主频带、相位、群时延和空间分布；
2. 覆盖层相对同坡角均质坡，在哪些频率和位置产生幅值、相位和时延修正；
3. 最近邻、POD-Ridge 和 POD-GPR 哪一种更可靠；
4. 代理复频响能否重构真实波下的时程、峰值时刻、PGA、TAF 和 5% 阻尼反应谱。

小论文只研究三个变量：

- 坡角 i；
- 覆盖层厚度比 d/h；
- 覆盖层与基岩波速比 rv。

其余条件固定：坡高 100 m、入射角 15°、密度比 0.85、二维线性两层坡、自由场场景、G1b 宽频多正弦输入、采样间隔 0.001 s、正式分析频带 0.5—10 Hz。

小论文不包含入射角扩展、密度比扩展、三层地层、EQL、TSSI、竖向代理和其他毕业论文扩展工况。V 批次只做数值验证，不进入物理统计和机器学习训练。

物理结果的参考线只用于人工判读：幅值变化约 10%、主峰频率移动约 0.20 Hz、相位变化约 10°、群时延变化约 0.02 s；非单调变化两侧幅度约 5% 以上。模型相对简单基线至少改善约 5% 时，才认为复杂模型有实质增益。
