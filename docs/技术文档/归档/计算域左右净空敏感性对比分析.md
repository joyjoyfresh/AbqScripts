# 计算域敏感性成对收敛分析

> 分析状态：六组补充组合均已完成计算和独立评价；本文件采用成对收敛方法重新分析。
>
> 分析方法：以当前最大域为临时参考，计算相邻计算域之间的直接成对差异；有符号峰值变化取代绝对值误差；收敛趋势（相邻误差递减）作为核心判据。
>
> 核心原则：计算域敏感性应通过"大域之间的直接收敛"证明，而不是通过"所有工况相对于最小域的差异"证明。

## 1. 结论摘要

成对收敛分析表明，`4H` 与 `6H` 之间的坡顶峰值幅值变化在阈值以内（`-4.0%`），但全场级指标（对数幅值 RMSE `0.095`、相位 RMSE `5.4°`）仍超过严格阈值。峰值幅值随计算域扩大持续下降且未单调收敛，表明波场尚未完全稳定。建议在有条件时增加一个 `8H` 工况以确认收敛趋势。

| 判断对象 | 结果 | 解释 |
| --- | --- | --- |
| `4H → 6H` 峰值 | 通过 | `B3` 条件下有符号峰值变化 `-4.0%`，在 `5%` 阈值内；`B6` 条件下仅 `+0.4%`。 |
| `4H → 6H` 全场 | 未通过 | 对数幅值 RMSE `0.095`（阈值 `0.05`）、相位 RMSE `5.4°`（阈值 `5°`）均超限。 |
| 峰值收敛趋势 | 非单调 | `B3` 下 `\|Δpeak\|` 序列为 `2.15% → 6.48% → 4.00%`，不满足单调递减。 |
| `3H → 6H` 底部深度 | 影响较小 | `S4` 上峰值变化 `-3.8%`，全场 RMSE `0.027`，低于侧向净空效应。 |
| 边界反射 | 全部在窗内 | 即使 `6H`，侧向反射时间 `2.0 s` 仍小于分析时长 `6.0 s`，依赖吸收边界。 |
| 正式取值 | 暂取 `4H` | 峰值指标已接近稳定，但全场收敛未完全确认；有条件时应补充 `8H` 验证。 |

## 2. 评价方法

### 2.1 与旧方法的核心差异

| 项目 | 旧方法（v1） | 成对收敛方法（v2） |
| --- | --- | --- |
| 参考基线 | `P061`（`1H`）为零误差基线 | 最大域（`6H`）为临时参考 |
| 峰值指标 | 绝对值峰值误差 `\|ΔA\|` | 有符号峰值变化 `(A_cand - A_ref) / A_ref` |
| 比较方式 | 所有候选对 `1H` | 相邻域直接成对（`1H↔2H`、`2H↔4H`、`4H↔6H`） |
| 收敛判据 | 相对 `1H` 的差异大小 | 相邻误差是否持续递减 |
| `1H` 的角色 | 统一零点基线 | 仅作为"小域可能失真"的警示工况 |

### 2.2 工况矩阵

| `DOM-S6-B6` | `6H` | `6H` | 最大域参考 |

### 2.3 成对比较方案

侧向净空分析（固定底部深度）：

- `S1-B3 ↔ S2-B3`
- `S2-B3 ↔ S4-B3`
- `S4-B3 ↔ S6-B3`
- `S2-B6 ↔ S4-B6`
- `S4-B6 ↔ S6-B6`

底部深度分析（固定侧向净空）：

- `S2-B3 ↔ S2-B6`
- `S4-B3 ↔ S4-B6`
- `S6-B3 ↔ S6-B6`

侧向比较使用坐标相位校正消除理论水平传播延迟；底部深度比较不做相位校正，报告完整差异。

### 2.4 收敛判定阈值

| 指标 | 阈值 | 说明 |
| --- | ---: | --- |
| 有符号峰值变化 | `≤5%` | 候选域与更大域的核心响应差异 |
| 峰值频率变化 | `≤0.2 Hz` | 约一个频率分辨率 |
| 对数幅值 RMSE | `≤0.05` | 全场幅值差异 |
| 相位 RMSE | `≤5°` | 全场相位差异 |
| 收敛趋势 | 相邻误差单调递减 | `E(4H,6H) < E(2H,4H)` |

## 3. 侧向净空成对收敛

### 3.1 `base_depth = 3H`

| 成对 | 有符号峰值变化 | `\|Δpeak\|` | `ln\|G\|` RMSE | 相位 RMSE | 群时延 RMSE |
| --- | ---: | ---: | ---: | ---: | ---: |
| `S1 → S2` | `-2.15%` | `2.15%` | `0.182` | `10.45°` | `0.107 s` |
| `S2 → S4` | `-6.48%` | `6.48%` | `0.142` | `8.15°` | `0.088 s` |
| `S4 → S6` | `-4.00%` | `4.00%` | `0.095` | `5.42°` | `0.060 s` |

**峰值趋势**：所有有符号变化均为负值——峰值随计算域扩大而持续降低。这意味着较小的计算域系统性地高估了坡顶放大效应。

**收敛性检查**：

- `ln|G|` RMSE 单调递减：`0.182 → 0.142 → 0.095`——是
- 相位 RMSE 单调递减：`10.45° → 8.15° → 5.42°`——是
- `\|Δpeak\|` 单调递减：`2.15% → 6.48% → 4.00%`——否

峰值幅值的非单调行为（`S2→S4` 的 `6.48%` 大于 `S1→S2` 的 `2.15%`）是一个值得关注的信号。可能原因是 `S1` 和 `S2` 的小域虽然波场不准确，但峰值恰好因边界反射与坡体散射的特定干涉而接近 `S4` 的值。

**`4H → 6H` 判定**：

| 指标 | 数值 | 阈值 | 结果 |
| --- | ---: | ---: | --- |
| 有符号峰值变化 | `-4.00%` | `≤5%` | 通过 |
| 峰值频率变化 | `0.0 Hz` | `≤0.2 Hz` | 通过 |
| 峰值位置变化 | `0.0 m` | — | 无偏差 |
| `ln\|G\|` RMSE | `0.095` | `≤0.05` | 未通过 |
| 相位 RMSE | `5.42°` | `≤5°` | 未通过 |

峰值指标满足要求，但全场级差异仍然显著。

### 3.2 `base_depth = 6H`

| 成对 | 有符号峰值变化 | `\|Δpeak\|` | `ln\|G\|` RMSE | 相位 RMSE | 群时延 RMSE |
| --- | ---: | ---: | ---: | ---: | ---: |
| `S2 → S4` | `-5.50%` | `5.50%` | `0.144` | `8.27°` | `0.089 s` |
| `S4 → S6` | `+0.38%` | `0.38%` | `0.097` | `5.55°` | `0.060 s` |

**`4H → 6H` 判定**：

| 指标 | 数值 | 阈值 | 结果 |
| --- | ---: | ---: | --- |
| 有符号峰值变化 | `+0.38%` | `≤5%` | 通过 |
| 峰值频率变化 | `+2.1 Hz` | `≤0.2 Hz` | 未通过 |
| 峰值位置变化 | `-245 m` | — | 显著偏移 |
| `ln\|G\|` RMSE | `0.097` | `≤0.05` | 未通过 |
| 相位 RMSE | `5.55°` | `≤5°` | 未通过 |

`B6` 条件下的峰值幅值几乎完全收敛（`+0.38%`），但峰值频率和空间位置发生了显著偏移（`+2.1 Hz`、`-245 m`），说明 `S4-B6` 和 `S6-B6` 的峰值出现在不同的物理位置和频率上。全场指标与 `B3` 条件下处于同一水平。

### 3.3 峰值收敛趋势总结

`B3` 下峰值随侧向净空的变化序列：

```text
S1(1H): 2.015  →  S2(2H): 1.972  →  S4(4H): 1.844  →  S6(6H): 1.770
         -2.15%          -6.48%           -4.00%
```

峰值持续下降，尚未出现平台。若以 `S6` 为临时参考，则 `S4` 的峰值相对误差约为 `(1.844 - 1.770) / 1.770 = +4.2%`。

`B6` 下峰值序列：

```text
S2(2H): 1.877  →  S4(4H): 1.774  →  S6(6H): 1.781
         -5.50%           +0.38%
```

`B6` 条件下峰值已在 `S4` 和 `S6` 之间趋于稳定（`+0.38%`），但峰值位置发生了跳跃（`s` 偏移 `-2.45`，即 `-245 m`），表明峰值可能在不同测点之间"跳动"而非平滑收敛。

## 4. 底部深度成对比较

### 4.1 固定侧向净空时的 `B3 → B6` 差异

| 成对 | 有符号峰值变化 | `ln\|G\|` RMSE | 相位 RMSE | 群时延 RMSE |
| --- | ---: | ---: | ---: | ---: |
| `S2-B3 → S2-B6` | `-4.79%` | `0.031` | `2.34°` | `0.020 s` |
| `S4-B3 → S4-B6` | `-3.80%` | `0.027` | `2.06°` | `0.017 s` |
| `S6-B3 → S6-B6` | `+0.59%` | `0.033` | `2.28°` | `0.019 s` |

底部深度的影响在所有侧向净空水平上都比较一致：峰值变化约 `3-5%`，全场 RMSE 约 `0.027-0.033`（远低于侧向净空效应），相位 RMSE 约 `2°`。这些数值均满足阈值要求。

注意 `S6` 下 `B3→B6` 的有符号峰值变化反转为正值（`+0.59%`），而 `S2` 和 `S4` 下均为负值。这说明底部深度效应与侧向净空存在一定耦合，但量级较小。

### 4.2 底部深度结论

在 `S4` 上，底部从 `3H` 增至 `6H` 对场形态的影响很小（`ln|G|` RMSE `0.027`，相位 RMSE `2.06°`），峰值变化 `-3.8%` 在阈值内。当前没有充分证据表明 `B6` 能替代 `B3` 成为更优的默认底部深度。

## 6. 边界反射诊断

| 工况 | 侧距 | 侧向反射时间 | 分析窗内反射 | `d/λ(4Hz)` | `d/λ(1Hz)` |
| --- | ---: | ---: | --- | ---: | ---: |
| `S1-B3` | `100 m` | `0.33 s` | 是 | `0.67` | `0.17` |
| `S2-B3` | `200 m` | `0.67 s` | 是 | `1.33` | `0.33` |
| `S4-B3` | `400 m` | `1.33 s` | 是 | `2.67` | `0.67` |
| `S6-B3` | `600 m` | `2.00 s` | 是 | `4.00` | `1.00` |

反射时间公式为 `t_return = 2 × d_side / c_min`，其中 `c_min = 600 m/s` 为覆盖层波速。

**所有工况的侧向边界反射均在分析时间窗（`6.0 s`）内返回**。即使 `6H`（`t_return = 2.0 s`），反射波也有 `4.0 s` 的时间与坡体波场叠加。因此当前结果完全依赖吸收边界条件（Stacey + Bielak 方案）来消除侧向反射。

无量纲距离 `d/λ` 的意义：

- `S4` 在主导频率 `4 Hz`（`λ=150 m`）处 `d/λ = 2.67`，侧边界已距坡体约 `2.7` 个波长。
- `S4` 在 `1 Hz`（`λ=600 m`）处 `d/λ = 0.67`，低频长波的侧边界仍然很近。
- 只有 `S6` 在 `1 Hz` 处达到 `d/λ = 1.0`。

这意味着低频成分（`1-2 Hz`）在所有计算域中都受到侧边界影响，而高频成分（`≥4 Hz`）在 `S4` 以上已相对安全。坡顶峰值频率 `1.9 Hz` 恰好在受影响频段内，这可能是峰值持续下降的原因之一。

## 7. 收敛状态判定

### 7.1 属于哪种情况

根据分析框架中的三种典型情况：

- **情况 A**（核心差异很小）：部分满足——峰值通过但全场未通过
- **情况 B**（RMSE 小但峰值变化大）：不完全——峰值也通过了
- **情况 C**（非单调）：部分——峰值非单调但场形态单调

当前结果介于情况 A 和情况 B 之间：

1. **峰值幅值**：`4H → 6H` 变化 `-4.0%`，在 `5%` 阈值内但已接近边界。
2. **全场差异**：`ln|G|` RMSE `0.095` 约为阈值 `0.05` 的 `1.9` 倍。
3. **峰值趋势**：持续下降且非单调收敛，表明波场尚未完全稳定。

### 7.2 与 H/P 参数效应的比较

按建议原则 `E_domain < E_physical / 3`：

- 若 H/P 最小效应为 `9%`，则域误差应 `≤3%`。当前 `4H→6H` 峰值变化 `4.0%` 已超过此限。
- 若 H/P 最小效应为 `15%`，则域误差应 `≤5%`。当前恰好满足。

因此，域误差是否可接受取决于 H/P 参数效应的实际大小。

### 7.3 是否需要 `8H` 工况

**建议增加 `S8-B3` 的理由**：

1. 峰值尚未收敛：从 `S1` 的 `2.015` 到 `S6` 的 `1.770`，峰值持续下降 `12%`，未出现平台。
2. `|Δpeak|` 非单调：`2.15% → 6.48% → 4.00%`，无法排除 `S6→S8` 可能出现大于 `4%` 的变化。
3. 低频段侧边界仍在影响范围内：坡顶峰值频率 `1.9 Hz` 对应波长 `316 m`，`S4` 侧距仅为 `1.3` 倍波长。

**暂不增加的理由**：

1. 峰值变化 `4.0%` 已在阈值内。
2. 全场指标（`ln|G|` RMSE、相位 RMSE）单调递减，方向正确。
3. 底部深度效应较小（`3-5%`），不会与侧向效应叠加产生更大偏差。

## 8. 取值建议

| 项目 | 建议 |
| --- | --- |
| 默认侧向净空 | 暂取 `4H`，有条件时补充 `8H` 验证 |

| `1H` 结果 | 仅作为小域失真警示，不作为参考基线 |
| `6H` 结果 | 作为当前最大域临时参考 |
