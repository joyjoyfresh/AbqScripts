# 当前配置旧图对照工况说明

_以当前 J0 生产配置为主体，仅替换旧图地形、入射角组合和 El Centro 输入_

---

## 🎯 诊断目标

本批次用于观察当前配置在旧图代表工况下会产生什么曲线，而不是复现旧模型。

唯一替换项为：

- 坡高改为 `H=50 m`
- 坡角改为 `i=75°`
- 入射角采用 `0° / 10° / 20° / 30°`
- 输入波采用旧 `El_Centro_scaled.txt`

材料、计算域、网格、阻尼、FD 自由场、时间处理、求解控制、QA 和当前原生 TAF 定义全部直接继承 `Autorun_ch4_J0_v1.py`。

> ⚠️ **废弃说明：** `Run/ch4_reference_replication_check/run-001` 是上一套“旧配置等价复现”工况，实验目的不正确，禁止启动。本说明只对应 `Run/ch4_current_config_reference_check/`。

当前几何的实际域宽为：

\[
L/H=(4+2)+\cot 75^\circ+(3+2)=11.267949
\]

坡顶位于当前全局 `x/H=6`，坡脚位于 `x/H=6.267949`，坡脚以下深度为 `3H`。这与旧图的 `8H` 域不同，正是本次需要保留的当前配置差异。

## 📍 绘图坐标

不改变当前模型几何，只在绘图阶段把坡顶平移到旧图位置：

\[
\xi=3+\frac{x-x_{\mathrm{crest,current}}}{H}
\]

随后截取 `0≤ξ≤8`。因此：

| **特征点** | 对齐坐标 |
| --- | ---: |
| 坡顶 | `ξ=3` |
| 坡脚 | `ξ=3+cot75°=3.267949` |
| 当前完整域 | 约 `-3≤ξ≤8.267949` |

横轴必须标记为 `legacy-aligned x/H`；它不是当前模型从左边界起算的全局 `x/H`。

## 🔍 TAF 口径

本批只跑 **4 个坡地工况**，不再增加配对平地。当前原生指标为：

\[
TAF_{h,\mathrm{current}}=
\frac{PGA_{h,\mathrm{slope}}}
     {PGA_{h,\mathrm{current\ same-side\ 1D}}}
\]

旧图使用：

\[
TAF_{h,\mathrm{old}}=
\frac{PGA_{h,\mathrm{slope}}}
     {PGA_{h,\mathrm{flat\ FE}}}
\]

两者分母不同。本次有意保留这个差异，因为目标是检查整个当前配置在相同地形和地震波下的表现，而不是再次恢复旧方法。输出 CSV 同时保存当前 `PGA_h`、当前一维分母 `FF_PGA_h` 和 `TAF_h`，可继续判断波峰波谷来自坡地响应还是参考场。

所有比较曲线均使用 `0.05H` 网格，**不使用移动平均、Savitzky–Golay 或低通平滑**。

## ▶️ 运行方法

普通 Python 静态检查：

```powershell
python Run\Auto_ch4\Autorun_ch4_current_config_reference_case.py --check-only
```

准备完成后启动四个 Abaqus 工况：

```powershell
python Run\Auto_ch4\Autorun_ch4_current_config_reference_case.py Run\ch4_current_config_reference_check\run-001 --run-all --workers 4
```

已有结果只重画：

```powershell
python Run\Auto_ch4\Autorun_ch4_current_config_reference_case.py Run\ch4_current_config_reference_check\run-001 --plot-only
```

诊断批不自动删除 `ODB`、`STA`、`MSG` 和 `INP`，便于发现曲线异常后检查边界荷载和节点时程。保留过程文件属于审计策略，不改变数值模型。

## 📊 输出与判读

四个工况完成后，`comparison/` 自动生成：

| **文件** | 用途 |
| --- | --- |
| `TAF-El_Centro-current-config-h50-i75-angles.png` | 当前配置四入射角 TAF |
| `TAF-El_Centro-old-vs-current-config-overlay.png` | 当前原生 TAF 与旧图逐角度叠加 |
| `PGA-El_Centro-current-config-h50-i75-angles.png` | 当前配置原始水平 PGA 波峰波谷 |
| `TAF-El_Centro-current-config-angleXX.csv` | 当前 PGA、当前分母、当前 TAF 与旧 TAF |
| `当前配置原始节点TAF长表.csv` | 未重采样的当前原始节点 TAF 审计表 |
| `当前配置与旧图TAF描述性差异.csv` | RMSE、P95、最大差异、相关系数和峰值位置 |

判读顺序为：

1. 先看 `PGA_h` 是否已出现与当前图相似的局部波峰波谷
2. 再看 `FF_PGA_h` 是否在坡脚两侧造成额外跳变
3. 最后看 TAF 的峰值位置、振荡空间尺度和随入射角变化是否与旧图不同

因为新旧 TAF 分母不同，差异指标只能描述“整个当前流水线与旧图相差多少”，不能作为同定义数值验证的误差门。
