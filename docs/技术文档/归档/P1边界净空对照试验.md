# P1 边界净空对照试验

## 目的

该试验针对 `P1win-L1-h50_i15_t20` 的 4 Hz 结果：右侧坡脚平台在观测窗内仍有持续低幅，而不是仅在端点出现孤立尖峰。试验保持观测窗不变，只外移人工边界，用于区分真实的斜入射地形散射与边界影响。

## 固定条件

| 项目 | 原窗口诊断 | 本次对照 |
| --- | ---: | ---: |
| 坡高 / 坡角 / 入射角 | 50 m / 15° / 20° | 50 m / 15° / 20° |
| 输入波 | 4 Hz Ricker | 4 Hz Ricker |
| 坡顶观测窗 | 5h | 5h |
| 坡脚观测窗 | 4h | 4h |
| 侧向净空 | 1h | 4h |
| 表面端点位置 | `s=-6, +6` | `s=-9, +9` |

因此，统一后处理的观测范围仍为 `s∈[-5, 5]`，但两端各新增 3h 的缓冲带。

## 判别准则

将新旧结果在 `s=3`、`s=5` 及 `AR_max` 处直接比较。

1. 三项变化均不超过 5%：右侧低幅区可暂定为斜入射下的真实散射/背坡阴影，随后再调整远场 QA 的取样位置；
2. 任一项变化超过 5%：原模型的边界缓冲不足，P1 正式批量前应加大净空，不能将当前右侧低幅直接解释为物理响应；
3. 无论哪种结果，都不应再以首末单个表面节点作为 2 Hz 的远场 QA 唯一依据，应在扩展缓冲带内设置代表性参考带。

## 海绵修复验证

当前模型已具备通过 `case_config.json` 注入 `boundary_cfg` 的能力，且海绵层单元通过网格连接关系计算质心，不再依赖无效的 `MeshElement.pointOn` 属性。

首次海绵测试按默认 `left/right/bottom` 三边施加。由于本模型坡脚处总深度仅 100 m，与海绵宽度 100 m 相同，底部海绵覆盖了 6,679 个单元并侵入整个场地，导致 `AR_max` 降低 27.1%、`s=3` 降低 26.1%、`s=5` 降低 25.6%，该参数组合已明确拒绝。

现已在建模脚本中新增 `boundary_cfg.sponge_sides`，默认仍为 `left/right/bottom` 以保持旧工况行为；本修复试验显式设置为 `left/right`，仅在两端各 2h 的最外缓冲带启用 5 级渐变阻尼海绵（贴边界附加阻尼比 30%），底部继续仅由 VAB 处理。

修复验证必须同时满足：模型日志显示“边界=left/right”的海绵已施加；右端 QA 不超过 5%；且 `s=3`、`s=5`、`AR_max` 相对无海绵 4h 对照的变化均不超过 5%。任一观察窗指标超限则拒绝该修复参数，避免以吸收物理响应换取 QA 通过。

横向海绵试验已执行：日志确认 `left/right` 海绵覆盖 1,500 个单元，且观察窗指标变化满足 5%（`AR_max` -1.53%、`s=3` +0.29%、`s=5` -1.86%），但右端 QA 反而由 6.26% 增至 12.59%。因此海绵不能作为该问题的修复手段；它会改变边界附近的等效自由场，而不能把仍包含地形散射尾波的边界点变成一维自由场点。

## 最终 QA 修复（2026-07-11）

根因不在 VAB 注入或观察窗内的边界反射，而在原 `farfield_qa()` 将最右端单节点直接同一维自由场比较。该节点即使外移至 `s=9` 仍包含来自坡体的散射尾波，故 1D 对拍的 6.26% 不能代表 `s∈[-5,5]` 内的结果不可靠；4h 与 1h 净空的全窗口 1,001 个统一 s 网格点最大差异仅为 0.639%。

`Postprocess_All_surface_v2.py` 现支持显式的 `qa_cfg.mode='window_convergence'`：它读取配置中指定的参考 `surface_results.npz`，对同一记录、同一统一 s 网格的 `TAF_h_comp` 逐点比较。仅在有效同点数达到 `min_points` 且最大差异不超过 `tol` 时，才将最终 `suspect` 置为 `false`。原始端点误差及 `qa_farfield_endpoint_suspect` 始终保留，避免丢失边界诊断证据；未配置该 QA 的普通工况仍执行原严格端点 5% 门槛。

本工况使用 1h 净空结果作为显式参考，`tol=5%`、`min_points=1000`。重跑后处理后最终结果为：`qa_status=pass_window_convergence`、`suspect=false`、有效同点数 1,001、最大相对差异 0.639%（`s=4.57`）；端点诊断仍记录为左 0.084%、右 6.258%、`qa_farfield_endpoint_suspect=true`。

## 当前 QA 语义（2026-07-24）

上述`suspect=false`是2026-07-11产物的历史字段。当前后处理不再用计算域收敛覆盖端点诊断：端点状态始终由`suspect`与`qa_farfield_endpoint_suspect`保留，窗口收敛单独写入`qa_window_convergence`并设置`qa_domain_pass`。未配置的门标记为`not_evaluated`；只有`qa_cfg.required`中列出的门参与整体通过判定。这样既不会把仍含散射尾波的端点伪装成一维自由场，也不会把已通过的全窗口计算域证据误写成时间门。

## H1—H3扩大域应用（2026-07-26）

H1—H3 `run-002`表明，P1控制工况中`1h→4h`稳定的结论不能直接外推到更陡坡、近临界斜入射和宽频输入：3个代表工况从`0.1h`增至`1.0h`后，全窗口`TAF_h_comp`最大变化仍为17.71%/4.22%/17.97%，H1与H3复频响幅相也超限。因此均质坡正式入口采用新的`4.0h`扩大域等级，在`run-003`中以`run-002`的`1.0h`结果作对照，阈值保持2%不变。该决定不是把P1单工况结果当作直接证据，而是复用其扩大域等级建立新的逐工况收敛证据。

后续建模脚本专项审计确认，H工况还存在`bottom_ymax_mode=local`这一平场验证无法辨识的坡地模型形式选择：局部柱高保证左右角点自由场连续，但会使水平底边参考输入随真实坡面高度变化。故`run-003`扩大域安排现已暂停，不再把净空增大视为唯一修复路径；目录保持`planned`且不得启动。底边参考场口径关闭、主脚本重新冻结后，才重新生成预生产目录。详细证据见[H均质坡锯齿曲线建模审计](H均质坡锯齿曲线建模审计.md)。
