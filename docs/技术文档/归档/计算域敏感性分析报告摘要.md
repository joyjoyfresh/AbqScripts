# 计算域敏感性分析报告摘要

> 本文件为计算域敏感性分析的最终报告摘要，可直接用于论文或答辩材料。
>
> 详细数据和分析过程见 [计算域左右净空敏感性对比分析](计算域左右净空敏感性对比分析.md)。

## 1. 方法

采用成对收敛方法，以当前最大计算域（侧向净空 `6H`、底部深度 `3H`）为临时参考解，对 7 组工况（侧向净空 `1H`/`2H`/`4H`/`6H`，底部深度 `3H`/`6H`）进行相邻域直接成对比较。侧向比较前消除坐标平移引起的理论水平传播相位差。有符号峰值变化取代绝对值误差，收敛趋势（相邻误差递减）作为核心判据。`1H` 不作为统一参考基线，仅保留为小域失真警示。

## 2. 工况矩阵

| 工况 | 侧向净空 | 底部深度 | 角色 |
| --- | ---: | ---: | --- |
| `P061` | `1H` | `3H` | 小域警示工况 |
| `DOM-S2-B3` | `2H` | `3H` | 中间工况 |
| `V004` | `4H` | `3H` | 候选生产域 |
| `DOM-S6-B3` | `6H` | `3H` | 大域参考 |

坡高 `H = 100 m`，坡角 `60°`，覆盖层 `Vs = 600 m/s`，基岩 `Vs = 2000 m/s`，入射角 `15°`，G1b 多频正弦输入。

## 3. 侧向净空收敛

### 3.1 相邻域成对差异（`base_depth = 3H`）

| 成对 | 有符号峰值变化 | `ln\|G\|` RMSE | 相位 RMSE | 群时延 RMSE |
| --- | ---: | ---: | ---: | ---: |
| `1H → 2H` | `-2.15%` | `0.182` | `10.45°` | `0.107 s` |
| `2H → 4H` | `-6.48%` | `0.142` | `8.15°` | `0.088 s` |
| `4H → 6H` | `-4.00%` | `0.095` | `5.42°` | `0.060 s` |

全场形态指标（`ln|G|` RMSE、相位 RMSE、群时延 RMSE）单调递减，方向正确。峰值幅值随计算域扩大持续降低（`2.015 → 1.972 → 1.844 → 1.770`），累计下降 `12%`，未出现收敛平台。

### 3.2 相邻域成对差异（`base_depth = 6H`）

| 成对 | 有符号峰值变化 | `ln\|G\|` RMSE | 相位 RMSE | 群时延 RMSE |
| --- | ---: | ---: | ---: | ---: |
| `2H → 4H` | `-5.50%` | `0.144` | `8.27°` | `0.089 s` |
| `4H → 6H` | `+0.38%` | `0.097` | `5.55°` | `0.060 s` |

`B6` 条件下峰值幅值在 `4H` 与 `6H` 之间几乎完全收敛（`+0.38%`），但峰值位置发生了跳跃（空间偏移 `-245 m`，频率偏移 `+2.1 Hz`），表明峰值可能在不同测点之间跳动而非平滑收敛。

## 4. 底部深度影响

固定侧向净空，`3H → 6H` 底部深度变化：

| 成对 | 有符号峰值变化 | `ln\|G\|` RMSE | 相位 RMSE | 群时延 RMSE |
| --- | ---: | ---: | ---: | ---: |
| `S2`（`2H`） | `-4.79%` | `0.031` | `2.34°` | `0.020 s` |
| `S4`（`4H`） | `-3.80%` | `0.027` | `2.06°` | `0.017 s` |
| `S6`（`6H`） | `+0.59%` | `0.033` | `2.28°` | `0.019 s` |

底部深度影响显著低于侧向净空效应，全场 RMSE 约 `0.03`，均满足阈值。在 `S4` 上，底部从 `3H` 增至 `6H` 对场形态的影响很小，当前没有充分证据表明 `6H` 能替代 `3H` 成为更优的默认底部深度。

## 5. 关键位置频响对比

| 位置 | 峰值变化（`1H → 6H`，`B3`） | 频率稳定性 | 域敏感性评价 |
| --- | --- | --- | --- |
| 坡顶（`s=0`） | `-12.2%`（`2.015 → 1.770`） | `1.8-2.0 Hz` 稳定 | 中——峰值未收敛但频率稳定 |
| 坡面（`s=0.5`） | `±2%` | `6.5-6.6 Hz` 稳定 | 低——对域大小不敏感 |
| 坡顶后（`s=-1`） | 跳动 `1.49-1.66` | `1.5-4.3 Hz` 跳动 | 高——多峰竞争 |
| 坡脚前（`s=2`） | `-12%` | `4.7-5.8 Hz` 跳动 | 高——多峰竞争 |

坡顶和坡脚对计算域大小敏感；坡面中部极稳定，不受域变化影响。坡顶后方和坡脚前方的峰值频率在不同工况间跳动，说明这些位置的频响曲线存在多个幅值相近的局部峰值。

## 6. 边界反射诊断

| 工况 | 侧距 | 侧向反射时间 | 分析窗内反射 | `d/λ`（`4 Hz`） | `d/λ`（`1 Hz`） |
| --- | ---: | ---: | --- | ---: | ---: |
| `S1` | `100 m` | `0.33 s` | 是 | `0.67` | `0.17` |
| `S2` | `200 m` | `0.67 s` | 是 | `1.33` | `0.33` |
| `S4` | `400 m` | `1.33 s` | 是 | `2.67` | `0.67` |
| `S6` | `600 m` | `2.00 s` | 是 | `4.00` | `1.00` |

反射时间公式为 `t_return = 2 × d_side / c_min`，其中 `c_min = 600 m/s` 为覆盖层波速。

所有工况的侧向边界反射均在分析时间窗（`6.0 s`）内返回，当前结果完全依赖吸收边界条件（Stacey + Bielak 方案）来消除侧向反射。`S4` 侧距 `400 m` 对应主导频率 `4 Hz` 处 `2.67` 个波长，但 `1 Hz` 处仅 `0.67` 个波长。低频成分（`1-2 Hz`）在所有计算域中均受侧边界影响，坡顶峰值频率 `1.9 Hz` 恰好处于该敏感频段，这可能是峰值随域扩大持续下降的原因之一。

## 7. 4H → 6H 收敛判定

| 指标 | `B3` 数值 | `B6` 数值 | 阈值 | `B3` 结果 |
| --- | ---: | ---: | ---: | --- |
| 有符号峰值变化 | `-4.00%` | `+0.38%` | `≤5%` | 通过 |
| 峰值频率变化 | `0.0 Hz` | `+2.1 Hz` | `≤0.2 Hz` | `B3` 通过 |
| 峰值位置变化 | `0.0 m` | `-245 m` | — | `B3` 无偏差 |
| `ln\|G\|` RMSE | `0.095` | `0.097` | `≤0.05` | 未通过 |
| 相位 RMSE | `5.42°` | `5.55°` | `≤5°` | 未通过 |
| 峰值单调收敛 | 否 | — | 是 | 未通过 |

## 8. 结论

1. **峰值指标**：`4H` 与 `6H` 之间坡顶峰值变化 `-4.0%`，在 `5%` 容许阈值内，核心响应指标初步满足要求。

2. **全场指标**：对数幅值 RMSE `0.095` 和相位 RMSE `5.42°` 仍超过严格阈值，全场级收敛尚未完成。

3. **底部深度**：`3H` 与 `6H` 之间差异较小（全场 RMSE `0.027`），不是主要敏感性来源。

4. **物理机制**：坡顶峰值频率 `1.9 Hz` 处于侧边界影响的低频敏感段，这可能是峰值随域扩大持续下降的原因。

5. **取值建议**：暂取侧向净空 `4H`、底部深度 `3H` 作为生产计算域。域不确定性包络为峰值 `±4%`、全场 `ln|G|` RMSE `0.095`。有条件时应补充 `8H` 工况以确认峰值收敛趋势。

6. **H/P 后续处理**：按 `E_domain < E_physical / 3` 原则，若 H/P 最小参数效应 `≥12%`，当前域误差可接受；若最小效应 `<12%`，需进一步验证。
