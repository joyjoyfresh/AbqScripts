**地震波在地下传播的数值模拟：计算逻辑解构**

------VAB 等效节点力法的波动核心（基于
VAB_oblique_TAF_multilayer_v8.py）

本文只讲一件事：脚本到底是怎么把地震波在地下的传播算出来的。不涉及几何、网格、输入输出，只聚焦波动核心。

核心是三块拼起来的：**一维分层自由场** + **粘弹性人工边界** +
**等效节点力**。下面逐块讲清公式，并配四个可以手算、数字与脚本一致的算例。

**1 方法总览：有限模型里如何装下半无限地下**

真实地下是半无限的，有限元只能截取一块有限区域。若直接截断，坡体散射出去的波会在人工边界上**反射回来污染结果**。这套方法（域缩减
/ 等效节点力 + 粘弹性人工边界）把总波场拆成两部分：

总波场 = 自由场（没有坡体时、水平成层地下对入射波的"背景"响应）+
散射场（坡体额外散射出来的波）。

于是分三步：

**① 一维分层自由场**：先解"无坡"时成层地下对斜入射 SV
波的响应（频域半解析，第 2 节）。

**②
等效节点力**：把该自由场以"集中力时程"施加到左/右/底三条人工边界，使模型内部自动重现自由场（第
4 节）。

**③
粘弹性人工边界**：同一批边界节点上接"弹簧+阻尼器"到地，吸收坡体散射、向无穷远辐射的波，杜绝反射（第
3 节）。

内部由 Abaqus
隐式动力积分求解连续介质方程，坡形带来的放大就自然叠加在自由场之上。

**2 一维分层自由场（fd 引擎：Thomson-Haskell 全局矩阵法）**

这是整套方法的"输入端"：必须先知道无坡时地下每一点的位移、速度、应力随时间怎么变。脚本在**频域逐频求解、再逆
FFT 回时域**。

**2.1 斜入射与 Snell 守恒**

入射 SV 波以角 θs 从基岩底部射入。水平慢度 p 全场守恒（Snell
定律），是贯穿所有层的不变量：

> p = sin(θs) / cs (cs = 基岩剪切波速)

各层的折射角由 p 反推：sin(α_layer) = p · cs_layer。

**2.2 每层的波场与极化**

任一层内，波场是上行/下行的 P 波与 SV
波的叠加。垂直慢度（复数，含衰减分支）：

> qs = sqrt(1/cs\^2 - p\^2), qp = sqrt(1/cp\^2 - p\^2)

四种波的极化向量 d（位移方向，对应论文式(2)）：

> Pu=(cp·p, cp·qp) Pd=(cp·p, -cp·qp)
>
> Su=(cs·qs, -cs·p) Sd=(-cs·qs, -cs·p)

单个波的位移（a=波幅，ky=±q 决定上/下行）：

> u = d · a · e\^{ iω(t - p·x) } · e\^{ -iω·ky·(y - yref) }

**2.3 应力由胡克定律给出**

对位移求导（∂/∂x → -iωp，∂/∂y → -iω·ky）代入本构：

> σyy = λ·∂ux/∂x + (λ+2μ)·∂uy/∂y
>
> σxy = μ·(∂ux/∂y + ∂uy/∂x)
>
> σxx = (λ+2μ)·∂ux/∂x + λ·∂uy/∂y (λ,μ=拉梅常数,剪切模量)

**2.4 求解：界面连续 + 自由面**

**未知量**：基岩里 2 个反射波(Pd,Sd) + 每个有限层 4
个波(Pu,Pd,Su,Sd)，共 4M+2 个波幅（M=有限层数）。

**方程（共 4M+2 条）**：

• 每个层间界面：位移 ux, uy 与应力 σyy, σxy 连续（4 条/界面）；

• 顶部自由地表：σyy = 0、σxy = 0（2 条）；

• 单位幅值的入射上行 SV 波是已知项，移到方程右端。

逐频率组装系数矩阵 A(ω) 与右端 b(ω)，解线性方程组得到全部波幅：

> A(ω) · a(ω) = b(ω) → a(ω) = 各未知波的复幅值

代码 \_fd_solve_column 对所有频点批量直解（np.linalg.solve 堆叠求解）。

**2.5 阻尼：复模量（与 Abaqus 瑞利阻尼一致）**

材料阻尼用复模量计入，使自由场的衰减与 FE 内部介质严格一致：

> ρ_c = ρ(1 - iα/ω), μ_c = μ(1 + iωβ), λ_c = λ(1 + iωβ)

（α,β = 瑞利阻尼系数，由各层品质因子 Q 反算，见脚本 perband 重锚定）。

**2.6 从输入地震波到每个节点的自由场时程**

1\) 读输入加速度记录 a(t)，FFT 得加速度谱 A(ω)；

2\) 位移谱 U0(ω) = -A(ω)/ω\^2（加速度两次积分）；

3\) 节点(x0,y0)的场量谱 = 单位入射解(在 y0 处) × U0(ω) ×
e\^{-iω·p·x0}（水平传播相位）；

> U_node(ω) = U_unit(ω, y0) · U0(ω) · e\^{ -iω·p·x0 }

4\) 逆 FFT 回时域，得该节点的 ux, uy、速度 vx, vy、应力 σxx, σyy, σxy。

**3 粘弹性人工边界（弹簧-阻尼器）**

每个边界节点接两组"弹簧+阻尼器"到地：法向一组、切向一组。系数乘以该节点的**影响长度
l**（相邻间距的一半之和，把分布边界离散到节点）：

> 法向: Kn = G/(2R)·l , Cn = ρ·cp·l
>
> 切向: Kt = G/(4R)·l , Ct = ρ·cs·l

（G=剪切模量, R=参考长度取模型最高点, cp/cs=纵/横波速, ρ=密度）。

**物理意义**：阻尼器系数 ρ·c 正是介质的波阻抗------它精确吸收以波速 c
正入射的外行散射波（不反射）；弹簧提供恢复刚度，防止低频零漂、保证静力稳定。

**4 等效节点力：把自由场注入有限模型**

把第 2
节算出的自由场，以集中力时程施加到边界节点，使内部重现自由场。每个节点的力
= 弹簧力 + 阻尼力 + 边界面力：

> 侧边(左/右): fx = Kn·ux + Cn·vx + l·tx , fy = Kt·uy + Ct·vy + l·ty
>
> 底边: fx = Kt·ux + Ct·vx + l·tx , fy = Kn·uy + Cn·vy + l·ty

其中 (ux,uy)=自由场位移, (vx,vy)=自由场速度,
(tx,ty)=自由场边界面力（应力·外法向，代码已嵌好符号：左
t=(-σxx,-σxy)，右 t=(+σxx,+σxy)，底 t=(-σxy,-σyy)）。

**妙处**：这三项合起来，恰好让"弹簧-阻尼器 +
等效力"的边界在自由场下处于平衡------于是内部精确重现自由场；当坡体散射出额外波时，弹簧-阻尼器又把它们吸收掉。各节点
fx(t)、fy(t) 作为幅值曲线 + 集中力施加。

**5 内部求解与放大量**

• 内部连续介质方程由 Abaqus 隐式动力(HHT-α,
TRANSIENT_FIDELITY)逐步积分求解：

> ρ·u\'\' + α·ρ·u\' = ∇·\[ σ(1 + β·∂t) \]

• 地形/分层带来的额外放大叠加在自由场之上；坡面各点峰值加速度 PGA
即结果。

**• 放大系数 TAF = 坡面 PGA / (factor_h × 输入波 PGA)**，分母正是算例 A
的基岩自由露头水平运动（1.92×输入）。

• 内置自检：建模前自动对拍两个解析解------半空间地表
\|ux\|=2.0（算例A退化），单层场地传递函数 vs SH
解析（算例B），误差\>1e-3 即中止，防止自由场被误改。

**6 一条龙小结**

输入加速度 → **FFT + Thomson-Haskell 分层求解** → 每个边界节点的自由场
u,v,σ → **×弹簧/阻尼系数 + 面力** → 等效节点力时程 →
施加到带粘弹性边界的有限元模型 → **Abaqus 隐式动力求解** → 坡面 PGA →
TAF。

**一句话**：自由场负责"喂入正确的背景波场"，弹簧-阻尼器负责"放走散射波"，二者合一，让一块有限模型在数值上等价于半无限的成层地下。
