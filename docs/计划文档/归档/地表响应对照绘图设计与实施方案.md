# 原始与重采样响应对照绘图实施计划

## 1. 目标
在每个工况的 `figs/` 中同时输出原始节点 `x → s` 图和统一网格重采样图。此操作用于检查从 `x → s → 统一网格重采样` 的数据流中是否引入了异常波动或削峰现象，从而确保后处理质量。

## 2. 数据流设计
1. `surface_response_<record>.csv`：直接从 ODB 中提取出来的逐节点原始指标。
2. 原始对照图：只调用已有的 `calc_s_coords()` 将原始的物理横坐标 `x` 换算为拓扑归一化坐标 `s`。此过程不进行插值、不补点、亦不进行任何重采样，以最大程度保真。
3. 现有重采样图：继续读取 `sgrid_response_<record>.csv` 这一已在重采样网格上生成的指标文件。

## 3. 实施方案
- **数据源复用**：复用 `Postprocess_All_surface_v2.py` 中现有的六面板绘图函数。
- **绘图接口改造**：为绘图入口函数 `plot_results()` 增加数据源标识参数。
  - 读取原始 CSV 数据后，调用已有的坐标换算函数 `calc_s_coords()`。
  - 读取重采样 CSV 后，直接绘制重采样后的 `s` 坐标。
  - 两种数据源共用相同的六面板布局、观测窗口、字段、颜色和坐标定义。
- **输出文件**：
  - `surface_response_<record>.pdf/png/svg`：现有统一重采样网格图。
  - `surface_response_raw_s_<record>.pdf/png/svg`：原始节点换算为拓扑坐标 `s` 后的对照图。

## 4. 约束与异常处理
- 原始对照数据只允许更换坐标，绝不允许在绘图前插值、补点或重采样。
- 不对原始 CSV、重采样 CSV 以及统计计算结果文件进行任何物理修改。
- 保持脚本的单文件自包含特性，不得添加额外的第三方库运行依赖。
- 若缺少原始或重采样 CSV 文件，应跳过对应图表的生成并记录日志，不致程序崩溃。
- 几何元数据不足或 `TAF_v` 全为 NaN 等异常时，保持面板为空，不构造任何虚拟数据。
