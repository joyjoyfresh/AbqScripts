# 毕业论文第四至第六章研究与实施总计划

_更新日期：2026-07-31_

本文管理毕业论文第四、五、六章的研究内容、工况预算和执行顺序。英文期刊小论文的80次工况和一个月排期见[英文期刊小论文研究与实施计划](英文期刊小论文研究与实施计划.md)。

## 0. 三章一条线：从场地，到结构，到代理

论文第四至六章不是三个并列的专题，而是同一个故事的三幕，按"场地→结构→代理"的顺序展开：

**第一幕（第四章）——场地。** 在谈结构之前，必须先把坡地本身讲清楚：斜入射成层坡地中，地形放大与地层放大何时可以近似相乘，何时必须考虑耦合？这一章不建结构，只研究自由场。

**第二幕（第五章）——结构。** 第四章给出了坡面自由场运动的定量图像，自然引出下一个问题：把建筑放上这样的坡顶，地形—土—结构相互作用（TSSI）何时减震、何时增震？

**第三幕（第六章）——代理。** 第四章的每一条复频响曲线都来自一次动力求解，全参数域要数百次。能否用代理模型学出第四章的映射，快速预测复频响，并在适用域外主动拒绝？

| 章节 | 核心问题 | 在故事中的角色 |
| ---- | -------- | -------------- |
| 第四章 | 斜入射成层坡地中，地形放大与地层放大何时可以近似相乘，何时必须考虑耦合？ | 建立物理机制与可分离边界 |
| 第五章 | 坡顶建筑的地形—土—结构相互作用（TSSI）何时减震、何时增震？ | 回答坡顶建筑的工程后果 |
| 第六章 | 能否用代理模型预测复频响，并在适用域外主动拒绝？ | 用数据驱动复现并替代昂贵求解 |

三章如何咬合：

- **四→六：数据与物理的接力。** 第四章是第六章唯一的数据源和物理约束。每个成层工况都有可追溯的 `H_1D` 和相同坡角的 `H_topo` 基线；第四章定义的可分离判据 `r_A`、`r_φ` 直接成为第六章的标签与验收口径；第四章划出的强耦合区域，正是第六章必须预测准、也必须知道何时拒识的区域。
- **四→五：概念衔接，数据独立。** 第五章的自由场模型与第四章同属自由场问题，概念上是"先有地面运动、再谈结构"的顺延；但引入结构、材料非线性和不同坡高尺度后，第五章的工况体系独立设计、独立运行，不与第四、六章共用数据，结论也互不引用。第五章是自成体系的应用章。
- **共同底座。** 三章共用同一套建模、后处理与批处理脚本，所有正式工况由同一个主清单领取，保证结果可追溯、可复现（见第4节）。

当前进度：第四章的数值可信性验证（G0—G1r）已全部通过，均质基线（H1—H3）的代表工况已完成；英文期刊J0支线的175个目录已生成但Abaqus未启动；第五章建模脚本P0改造已落地但未批量验证；第六章代理模型尚未开始训练。

## 1. 第四章——斜入射成层坡地参数分析

论文的物理链条从自由场开始。这一章只回答场地问题：地形效应和地层效应各自放大多少，两者叠在一起时是简单相乘还是发生耦合。答案直接决定第六章的学习目标怎么设，也为第五章提供"为什么坡顶结构不能套用平地结论"的物理背景。

### 1.1 研究问题

为回答上述问题，第四章围绕五个可证伪假设展开：

| 编号 | 假设 | 不成立时怎么办 |
| ---- | ---- | -------------- |
| HP1 | 不同宽频激励提取的复频响在共同有效频带内一致 | 修正信号链，不扩大样本 |
| HP2 | 一维场地主峰与均质地形主峰接近时，耦合残差增大 | 缩小"强耦合"区域 |
| HP3 | 分别保留波速比与密度比，比只用阻抗比更能解释残差 | 回到阻抗比简化模型 |
| HP4 | 学习物理残差比直接学习总频响盲测误差更低 | 第六章采用更简单路线 |
| HP5 | 超出两层体系时必须由确定性规则拒绝 | 收窄适用域 |

其中HP4、HP5是与第六章的接口假设：第四章先提出"学残差更优、域外必须拒绝"的猜想，第六章用盲测和OOD实验给出判决。

### 1.2 范围

**包含：**

- 二维平面应变坡地自由场，不建结构；
- 土体线弹性，等效线性（EQL）仅作条件扩展；
- 均质坡与一个水平覆盖层+基岩的两层坡；
- 五个输入变量：坡角 `i`、入射角 `θ`、厚度比 `d/h`、波速比 `r_v`、密度比 `r_ρ`；
- 复频响 `H(f,s)` 为学习主目标，同时保留幅值和相位。

**不包含：**

- TSSI、结构响应和第五章工况；
- 土体真非线性、孔压和液化；
- 多层地层（仅作为结构化域外挑战）；
- 额外坡高（只用于尺度一致性核验）。

### 1.3 核心定义

**复频响**——以基岩上行SV波加速度谱为分母：

$$
H_{2D,k}(f,s)=\frac{\widehat A_{\mathrm{surface},k}(f,s)}{\widehat A_{\mathrm{incident}}(f)},\qquad k\in\{x,z\}
\tag{1}
$$

**复数耦合比**——判断地形与地层能否相乘分离：

$$
R_c(f,s)=\frac{H_{2D,x}(f,s)}{H_{1D}(f)\,H_{\mathrm{topo}}(f,s)}
\tag{2}
$$

其中 `H_1D` 是同地层一维自由场频响，`H_topo` 是相同坡角但无覆盖层的均质坡复频响。

**可分离判据**——用耦合比的幅值和相位分别衡量：

$$
r_A(f,s)=\ln|R_c(f,s)|,\qquad r_\phi(f,s)=\operatorname{wrap}\{\arg R_c(f,s)\}
\tag{3}
$$

`r_A` 接近零且 `r_φ` 接近零时可分离；超出阈值时为强耦合。

**傅里叶谱放大系数**由复频响幅值确定性派生，不是独立数据：

$$
FSAF_{\mathrm{inc},k}(f,s)=|H_{2D,k}(f,s)|
\tag{4}
$$

**反应谱放大系数**——5%阻尼，两种参考口径：

$$
RSAF_{\mathrm{rock},x}(T,s;g)=\frac{S_{a,2D,x}(T,s;g)}{S_{a,\mathrm{rock,ff},x}(T;g)},\qquad RSAF_{\mathrm{1D},x}(T,s;g)=\frac{S_{a,2D,x}(T,s;g)}{S_{a,1D,x}(T;g)}
\tag{5}
$$

这套定义是第四、六章的共同语言：式(1)是第六章的主输出，式(2)—(3)是第六章的残差标签与判据。

## 2. 第五章——坡顶建筑TSSI研究

第四章讲清了坡面上的运动，第五章把框架结构放上坡顶，论文视角从"地"转向"地上的结构"。这一章回答的是工程后果：同样建在坡顶，TSSI有时减震、有时增震，分界在哪里。需要强调的是，第五章虽然在概念上承接第四章，但它的坡高尺度、结构建模和材料非线性都是另一套问题，因此工况与数据完全独立——第四章提供的是动机，不是输入。

### 2.1 研究问题

| 编号 | 问题 | 可检验假设 |
| ---- | ---- | ---------- |
| Q1 | 地形放大与结构动力放大能否相乘分离？ | 总放大 ≈ TAF × 固定基础放大，残差为TSSI耦合项 |
| Q2 | 坡顶SSI何时减震、何时增震？ | 取决于周期延长后T_ssi相对坡顶反应谱峰的移动方向 |
| Q3 | 距坡缘多远地形效应对结构可忽略？ | 退让距离超过(2—4)倍坡高后趋于平地SSI |
| Q4 | 结构非线性如何反馈TSSI？ | 损伤致周期延长与SSI延长叠加，改变损伤沿高分布 |
| Q5 | 摇摆/竖向分量贡献多大？ | 斜入射+坡肩不对称使基础摇摆角显著大于平地 |

Q1与第四章的可分离问题是同一思想在结构层面的镜像：第四章问"地形×地层能否相乘"，第五章问"地形×结构能否相乘"。两章各自独立作答，结论互相印证但不互相引用。

### 2.2 范围

**包含：**

- 坡顶框架结构（3/5/8层），固定基础与SSI两种场景；
- 均质岩坡和上软下硬两层坡；
- 坡角30°/45°/60°，坡高50 m（主）和200 m（对照）；
- 入射角0°/15°/30°；
- 弹性与CDP混凝土非线性；
- 距坡缘距离M/B扫描（0—5倍基础宽度）。

**不包含：**

- 3D模型、桩基、结构群相互作用（列入期刊拓展）；
- 土体真非线性（时域自由场替换频域引擎属于后续工作）。

### 2.3 三胞胎工况法

每组参数运行三个模型：

1. **freefield**：无结构，出坡顶自由场运动；
2. **fixed**：框架基底施加freefield运动（去耦）；
3. **ssi**：全耦合模型。

同几何同波下freefield可被不同结构共用，降低成本。三模型对比恰好把Q1的乘积近似拆成可检验的三项：freefield给出地形放大，fixed给出结构动力放大，ssi与两者的乘积之差即为TSSI耦合项。

## 3. 第六章——机器学习代理模型

第六章回到第四章的数据，回答一个方法论问题。第四章每得到一条复频响曲线都要一次动力求解，主参数域全跑完要数百次（见1.4节工况预算）；如果每次工程评估都重新求解有限元，第四章的规律就只能停留在论文里。第六章因此尝试用代理模型学习第四章建立的映射，并且把第四章的两个猜想（HP4、HP5）变成可判决的实验：三条学习路线正是可分离问题的镜像——M1直接学总频响，M2先除掉一维地层主效应，M3只学耦合残差，哪条路线更好，本身就是对第四章可分离判据的一次数据驱动检验。

### 3.1 研究问题

| 编号 | 问题 |
| ---- | ---- |
| RQ6-1 | 直接学习 `H_2D`、学习 `H_2D/H_1D` 还是学习耦合残差 `R_c`，哪条路线盲测误差最低？ |
| RQ6-2 | 预测的复频响能否重建未见真实波的时域和反应谱指标？ |
| RQ6-3 | 不确定性与OOD门控能否识别域外输入和多层拓扑？ |
| RQ6-4 | 复杂模型相对物理乘积和简单插值基线是否有实质增益？ |

四个问题与第四章一一对应：RQ6-1判决HP4，RQ6-3判决HP5，RQ6-4判决"数据驱动相对第四章物理乘积近似是否有增益"，RQ6-2则检验代理预测能否走通第四章G1r已经验证过的真实波闭环。

### 3.2 范围

**包含：**

- 两层坡水平复频响 `H_x(ξ_f, s)` 为主目标，竖向 `H_z` 为次目标；
- 五个输入：`[i, θ, d/h, r_v, r_ρ]`；
- 均质坡代理：输入 `[i, θ]`；
- POD降阶 + GPR/XGBoost/Ridge；
- 冻结盲测（L3）、结构化OOD（L5）、真实波闭环（W0）和同机复现（R0）。

**不包含：**

- TSSI和第五章数据；
- EQL数据混入训练；
- 多层地层伪装成两层样本；
- 地震波特征作为工况输入（真实波只用于闭环验证）。

### 3.3 核心公式

第六章的输入输出完全沿用第四章的定义，保证两章口径一致。

**两层坡输入：**

$$
\mathbf{x}=[i,\,\theta,\,d/h,\,r_v,\,r_\rho],\qquad r_v=V_{s,c}/V_{s,b},\qquad r_\rho=\rho_c/\rho_b
\tag{6}
$$

**均质坡输入：**

$$
\mathbf{x}_{topo}=[i,\,\theta]
\tag{7}
$$

**主输出——复频响：**

$$
H_{2D,k}(\xi_f,s)=\frac{\widehat A_{\mathrm{surface},k}(\xi_f,s)}{\widehat A_{\mathrm{incident}}(\xi_f)},\qquad k\in\{x,z\}
\tag{8}
$$

**主残差——耦合比：**

$$
R_c(\xi_f,s)=\frac{H_{2D,x}(\xi_f,s)}{H_{1D}(\xi_f)\,H_{topo}(\xi_f,s)}
\tag{9}
$$

频率 `ξ_f` 和位置 `s` 是输出场坐标，不是独立训练样本。一个物理工况才是一个样本。

### 3.4 模型比较

| 编号 | 方法 | 作用 |
| ---- | ---- | ---- |
| B0 | 解析 `H_1D` | 无地形的物理下限 |
| B1 | `H_1D × H_topo` | 可分离物理基线 |
| B2 | 最近邻/插值 | 判断ML是否必要 |
| B3 | Ridge预测POD系数 | 简单统计基线 |
| M1 | 直接学习 `H_2D` | 端到端基线 |
| M2 | 学习 `H_2D / H_1D` | 去除一维层状主效应 |
| M3 | 学习 `R_c` | 只学耦合残差（主创新候选） |

GPR为主力不确定性模型，XGBoost为非线性对照。复杂模型不能稳定优于B1/B3时，选更简单路线。其中B1就是第四章的乘积近似本身——第六章的任何增益都必须先赢过第四章已经给出的物理答案。

### 3.5 防泄漏规则

1. 物理工况整体划分，频率和空间点不得跨集；
2. L3在模型开发前生成、散列并密封；
3. 测试工况的 `H_topo` 必须由训练折拟合的 `S_topo` 预测；
4. 标准化、POD和超参数全部在折内完成；
5. 主动学习只读开发集信息；
6. v3与v4不混训、不拼接。

### 3.6 验证层级

| 层级 | 数据 | 回答 |
| ---- | ---- | ---- |
| 内部验证 | L2分组交叉验证 | 模型选择 |
| 冻结盲测 | L3 | 域内真实泛化 |
| 结构化OOD | L5 | 能否拒绝域外输入 |
| 工程闭环 | W0、M0、R0 | 未见波形闭环、拓扑拒识、流程复现 |

主要指标：`log|H|` MAE、相位圆周RMSE、复数NRMSE、分区误差、重建PGA/PGV/Sa误差、80%/95%区间覆盖率。四层验证的数据池全部在第四章工况设计时已同步封存（见1.4节），物理生产与代理验证共用同一份工况，不留两套口径。

### 3.8 可形成的结论
