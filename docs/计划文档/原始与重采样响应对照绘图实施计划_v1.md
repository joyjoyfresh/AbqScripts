# 原始与重采样响应对照绘图实施计划

> **执行要求：** 使用测试驱动方式逐步实现并验证。

**目标：** 每个工况同时输出原始节点 `x→s` 图和统一网格重采样图。

**方案：** 复用 `Postprocess_All_surface_v2.py` 现有六面板绘图函数。为绘图入口增加数据源参数：原始 CSV 读取后调用既有 `calc_s_coords()`，重采样 CSV 直接读取 `s`；其余布局逻辑共用。

**技术栈：** Python、NumPy、Matplotlib、标准库 unittest。

## 约束

- 原始对照数据只换坐标，不插值、不补点、不重采样。

- 保持脚本单文件、自包含，不增加运行依赖。
