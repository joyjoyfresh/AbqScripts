# **研究计划** 

## **1. 工况怎么设计**

### **1.1 用无量纲参数，不用绝对量**

这是全计划最关键的一条（对应 v2 的 C2）。**绝对坡高 h 换不了刻度就外推崩溃，无量纲量才能跨尺度推广。** 五个控制参数：

|  |  |  |  |
|:--:|:--:|:--:|:--:|
| **参数** | **含义** | **建议范围** | **为什么** |
| η = h/λ = h·fr/Vs | 坡高/波长比 | 0.1 ~ 2.0 | 地形放大第一控制量 |
| i | 坡角（坡面倾角，度） | 15, 30, 45 | 几何主因 |
| θ | SV 波入射角（度） | 0, 10, 20, 30 | **≤ 临界角 32.3°（ν=0.3），\>30° 仅告警** |
| d/h | 覆盖层厚 / 坡高 | 0.2 ~ 2.0 | 地层共振控制量 |
| α = ρ₂Vs₂/ρ₁Vs₁ | 阻抗比（基岩/覆盖层） | 1.25 ~ 4.0 | 共振强弱，你现有 Vs=2000/1600≈1.25 是下限 |

附带派生量（后处理时算，不单独采样）：场地卓越周期 Ts = 4·Σ(dᵢ/Vsᵢ)，输入卓越周期 Tp = 1/fr，共振判据 Tp/Ts。

### **1.2 采样方法：拉丁超立方（LHS），不要全因子**

全因子会爆炸（5 维各 5 档 = 3125 个，个人电脑跑不完）。做法：

**1. 首批 120~180 个工况**：在 \[η, i, θ, d/h, α\] 五维空间做 LHS（或 Sobol 序列）采样。Python 用 \`scipy.stats.qmc.LatinHypercube\`。

**2. 主动学习补点 50~100 个**（对应 C5）：首批训练 GPR 后，在候选空间算预测方差 σ²，挑 σ² 最大的 30~50 个点再跑，重复 2~3 轮。

**3.** 总计 **200~300 个工况**，约个人电脑 3~4 个月夜间产能。

**4.** 另留 **10~15 个工况跑真实地震波**，专门用于验证"H(f) 卷积合成 vs 直接 FEM"的闭环误差。

**5. 把现有 174 个均质工况并入**：它们是 α→1（无阻抗差）、d/h→任意的退化子集，白赚训练样本。

### **1.3 命名规范**

沿用你现有风格扩展：\`fuke-ALL-h{h}\_i{i}\_angle{theta}\_d{d}\_a{alpha}\`。每批夜间任务生成一个 \`manifest.csv\`（参数表 + 完成状态 + 校验和），方便断点续跑和追溯。

## **2. 模型尺寸怎么设计**

### **2.0 核心约定：一切以 h（坡高）为基准，total_L 自由浮动**

**先想清楚一个解耦**：FEM 那侧用**米**建模，ML 那侧用**归一坐标**学习，**h 是两者之间的换算桥**。模型多长多高（绝对米数）随工况变，ML 根本看不到——它只看无量纲特征 + 归一坐标上的曲线。所以：

- **不要去固定 total_L**。坡面水平长 = h/tan(i) 随坡角变，total_L 本来就该随 h、i 浮动，让它浮动是对的。

- 要固定的是**观测范围**（你想看坡顶/坡脚各多远）和**目标向量长度**（见 §4.0 三段坐标），这两个才是 ML 关心的，且都与绝对尺寸无关。

- 这样修掉了 v1 的矛盾：v1 把 total_L 写死成 1800 m，大坡高（h=200）时坡顶平台只有 5h、放不下 x/h=8，且不同 h 工况覆盖不一致。

### **2.1 几何尺寸：各段写成 h 的倍数**

设你要研究整个地表（坡顶+坡面+坡脚，见 §4），坡顶观测范围 A_max·h、坡脚观测范围 C_max·h（推荐 **A_max=5、C_max=4**，可配置；地形放大一般 x/h≈3~4 即衰减回 1，留 2h 净空到边界）：

|  |  |  |
|:--:|:--:|:--:|
| **部位** | **公式（h 为单位）** | **说明** |
| 坡顶平台 | (A_max + 2)·h | 观测窗 A_max·h + 左边界净空 2h；**与 i 无关** |
| 坡面水平长 w_slope | h / tan(i) | 由坡高、坡角决定，随 i 浮动 |
| 坡脚平台 | (C_max + 2)·h | 观测窗 C_max·h + 右边界净空 2h |
| **总长 total_L** | **(A_max+2)h + h/tan(i) + (C_max+2)h** | 随 h、i 浮动，不固定 |
| 覆盖层厚（坡顶下）d | (d/h)·h | 由无量纲参数反算 |
| 基岩厚（最深覆盖层之下） | ≥ 2h | 底部 VAB 净空 |
| 总高 H_model | (d/h)·h + 坡高落差 + 2h | 让体波发育、底边界够深 |

举例：i=45、A_max=5、C_max=4、h=200 → total_L = 7h + h + 6h = 14h = 2800 m（v1 写死的 1800 偏小约 1.5 倍，这正是矛盾来源）。坡顶平台 = 7h = 1400 m（v1 仅 1000）。**按这套，每个工况坡顶 \[0,A_max\]、坡脚 \[0,C_max\] 都被保证干净覆盖。**

**低 η（长波）净空兜底**：η=0.1 时 λ=10h，是很长的波。VAB（粘弹性人工边界）+ 逐节点 fd 自由场输入能吸收，所以仍按 h 定净空即可——这正是这套边界方法的价值。靠数据兜底：每个工况自动比对远场柱 vs \`ff_theory\` 一维理论解，**偏差 \>5% 才把该类工况侧向净空临时加到 \`max(2h, 0.25·λ_max)\`**，不要一刀切放大所有模型。

### **2.2 怎么落到脚本：加前置换算，别手改脚本**

脚本输入是绝对量（total_L、left_flat、bedrock_thickness…）。做法：**写一个前置换算**，给定无量纲量（h 作尺度 + i、θ、d/h、α、A_max、C_max）→ 按 §2.1 公式算出绝对尺寸 → 写进 \`case_config.json\` 注入（v8 已支持）。LHS 采样器（§7 清单 N5）顺手就把这步包了：采样无量纲参数 → 换算绝对尺寸 → 生成工况文件夹。

### **2.3 网格尺寸（最重要，按波长定，与 h 缩放无关）**

**按最软层 + 最高频率控制**（Kuhlemeyer-Lysmer 判据）

单元类型 **CPE4R**（4 节点平面应变缩减积分）。**参数设计第一步就要定"软层 Vs 下限 + 截止频率"**，否则网格量失控、单算例跑不动。

### **2.4 时间步与时长**

- 时间步 dt：满足采样定理，脚本自动校验。

- 分析步时长：覆盖输入波持续 + **静默尾段 \`tail_seconds=2~3 s\`**（v8 已支持）——让坡体混响衰减干净，频域提取 H(f) 才不泄漏。这是频域路线的硬保障。

### **2.5 地震动输入：宽频脉冲（频域路线的关键）**

线弹性下传递函数 H(f) 与输入波无关，所以**每个几何只需跑 1 次宽频脉冲**就能一次性提取整条 H(f, s) 曲面（s 为 §4.0 的三段归一坐标），数据效率比"每几何 × 3 条波"提高 3 倍。

- 主脉冲：Ricker 子波，中心频率 fc≈4 Hz（有效带宽 ~1~10 Hz）。

- **补一条 fc≈1.5~2 Hz 的 Ricker**，因为低频端（场地基频 ~0.44 Hz 附近）单条 4Hz 能量不足。两条合并保证 0.5~10 Hz 全覆盖。

- 入射角 θ 达到/超过 SV→P 临界角（32.3°）时 v8 直接拒绝建模（超临界非均匀波下解析分母失效）。

## **3. 需要保留什么数据**

**只存有用的，ODB 提取完即删**（个人电脑磁盘有限）。

### **每个工况一个文件夹**

**1. 地表全部节点的加速度时程**（TOP_SURFACE 节点集，A 全时程）——频域框架必须有全时程，**不能只存 PGA**。这是相对之前 数据管线最大的一处改动。

**2.** 地表节点坐标（用于算三段归一坐标 s = a/ξ/c，须含坡顶棱、坡脚棱位置）。

**3.** \`case_meta.json\`：该工况全部参数 + fc + 阻尼系数 + 一维理论台阶 \`ff_theory\`（远场 QA 用）+ 自检结果 \`selfcheck\`。

**4.** 输入波时程（合成时用）。

## **4. 数据怎么后处理**

后处理脚本（建议 \`Postprocess_H_v1.py\`，单文件、普通 Python 即可跑，不进 Abaqus）。

### **4.0 核心约定：三段归一化坐标 s（研究整个地表的关键）**

要把**整个地表（坡顶平台 + 坡面 + 坡脚平台）**作为目标，又要让不同工况能对齐进同一个矩阵给 POD/ML 用，**不能用单一 x/h**——因为坡面在 x/h 上的跨度 = 1/tan(i) 随坡角变、坡脚棱位置会漂移、拐点糊掉。正解是**按拓扑分三段，每段用自己的特征长度归一化，再首尾拼接，这样做的优势是**：

- **向量长度固定**：每个工况目标向量都是 N_A+N_B+N_C 点——这才是你真正想"固定的总长度"，它固定在 ML 向量这一层，不是物理米数那一层。

- **拐点严格对齐**：坡顶棱永远在 A/B 交界、坡脚棱永远在 B/C 交界，对所有工况一致，POD 压缩干净、不糊。

- **坡角 i 进特征、不进坐标**：陡坡坡面物理上短、缓坡长，这个差异由 ξ 归一到 \[0,1\] 自动吸收；"坡面物理多长"由 i 作为特征告诉模型。

**两步对齐**（回答"为什么要归一化 + 为什么要重采样"）：① 用 h / 各段特征长度归一化 → 把**范围**对齐；② 把每段插值到统一的 s 子网格 → 把**采样点位置**对齐（FEM 节点按波长布点、在 s 上位置和密度本就因工况而异，重采样是拉齐它们的必经一步）。

**分辨率校核**：段内节点数 ≈ X·h/Δl ≈ 25·X·η（X 为该段归一跨度）。η 越大波越短、形态越尖、FEM 给的节点也越多——网格在最需要分辨率处自动给得最多。所以一套按"最尖锐工况"定的子网格对所有工况安全：高 η 刚够用，低 η 过采样但因场光滑而无害。推荐 **N_A≈120、N_B≈60、N_C≈80**（坡顶段加密近坡顶棱），具体按段内最 wiggly 工况定。

### **4.1 工程量线（给 B4 对比 + 直观结果）**

对每个地表点：取加速度时程峰值 = PGA；除以同高度一维自由场 PGA = **TAF**（地形放大系数）。整理成 TAF 曲线，横轴用三段坐标 s。**招牌量 AR_max（峰值放大）必须在重采样之前从原始曲线精确提取**，连同它落在哪一段、哪个归一坐标，单独存为标量——任何重采样都可能挪峰/削峰，标量峰值要精确。

### **4.2 频域线（核心，对应 C1）**

对每个地表点和参考输入点：

得到传递函数曲面 H(f, s)（(N_A+N_B+N_C) 空间点 × ~100 频点）。要点：

**1. 相干函数筛选**：输入谱接近零的频段 H 会发散，用相干函数 \< 阈值的频点剔除，只保留 0.5~10 Hz 可靠带。

**2. 一维理论对拍 QA**：远场列（段A 最后端 / 段C 最前端的平台远端）的 H 应与 \`case_meta\` 里的 \`ff_theory\`（Thomson-Haskell 传递矩阵解）逐频吻合 ±5%，超差则该工况标记存疑、排查阻尼标定/边界污染。

**3. 三波互验（用现有数据）**：若旧 ODB 还在，3 条波各反演一个 H，线弹性下三者应一致，其离散度 = 数值噪声的免费估计。

## **5. 机器学习怎么用这些数据**

升级脚本 \`train_v4.py\`（大改动开新版，v3 流程整体复用）。

### **5.1 特征矩阵 X（无量纲）**

\`\[η, i, θ, d/h, α, Tp/Ts\]\`，约 6~10 维，仍在 GPR/XGBoost 舒适区。**关键**：把 v3 的绝对量 h 换成 η = h·fr/Vs，留一高度的 R² 就能从负值（h=10→-6.8, h=400→0.02）转正。

### **5.2 目标 Y 与降维**

- **主目标**：定义在三段坐标 s 上的传递函数曲面 H(f, s)。曲面太大，用 **二维 POD（对矩阵做 SVD）压缩**，预计 20~40 个模态够用（v3 经验：161 维曲线 15 个主成分重构 MAE 0.012）。先画奇异值衰减曲线定模态数。三段拼接的折角不影响 POD——只要拐点对齐（§4.0），分段光滑曲线照样压得动。

- **AR_max 标量单独回归**：峰值放大是招牌工程量，单独作一个标量目标（或多目标的一维）用精确值训练，不靠曲面还原，避免重采样误差。

- 工程派生目标 TAF / Sa比：由预测的 H(f) 卷积任意输入波后在时域算，**自动对任意波成立**（虚拟传感器）。

### **5.3 数据划分：GroupKFold（防泄漏）**

按几何工况分组做 5 折，确保同一地形的所有样本同进同出训练/测试，否则会数据泄漏、虚高。**绝不用随机 CV**——这正是 Ju 等(2024) 高估外推的根源。额外做留一波 / 留一几何外推测试，作为诚实的泛化证据。

### **5.4 模型**

- **GPR（主力）**：RBF 核 + WhiteKernel，自带不确定性 σ。\`MultiOutputRegressor\` 预测多个 POD 系数 → 逆 POD 还原曲面。

- **XGBoost（次优 + 可解释）**：提供特征重要性，配 SHAP。

- 训练成本 CPU 秒级，不需要 GPU。

### **5.5 残差学习**

不要让 ML 直接学总放大，做物理分解，只学小残差：

残差显著偏离 1 的参数区，就是"规范把地形系数和场地系数简单相乘"出错的区域 —— 直接的科学/工程产出。

### **5.6 可解释性 + 不确定性 + 适用域**

- **SHAP**：对 XGBoost 用 TreeSHAP，输出每个无量纲特征的贡献度和交互效应（重点看 η×α 耦合）。

- **UQ 校准**：检验 GPR 预测区间的名义覆盖率 vs 实际覆盖率（可靠性图）。

- **适用域判别器**：任意新输入算"可信/外推预警"标签（GPR σ 阈值 + 训练集凸包距离），强制在输出里显示。
