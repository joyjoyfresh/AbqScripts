# 原始与重采样响应对照绘图设计 v1

## 目标

在每个工况的 `figs/` 中同时输出两套同版式图，用于检查 `x → s → 统一网格重采样` 是否引入异常。

## 数据流

1. `surface_response_<record>.csv` 是直接从 ODB 提取的逐节点指标。
2. 原始对照图只调用现有 `calc_s_coords()` 将 `x` 换算为 `s`，不插值、不补点、不重采样。
3. 现有图继续读取 `sgrid_response_<record>.csv`。

## 输出

- `surface_response_<record>.pdf/png/svg`：现有统一网格图。
- `surface_response_raw_s_<record>.pdf/png/svg`：原始节点换算为 `s` 后的对照图。

两套图使用相同的六面板布局、观测窗口、字段、颜色和坐标定义。原始 CSV 与统计结果不修改。

## 异常处理

- 缺少原始或重采样 CSV 时只跳过对应图并记录日志。
- 几何元数据不足、无法计算 `s` 时沿用当前错误处理。
- `TAF_v` 全为 NaN 时保持空面板，不构造不存在的数据。

## 验证

- 单元测试确认原始 `x` 按既有几何关系正确转换为 `s`。
- 对 smoke 工况直接复用已有 CSV 重跑绘图，不重新运行 Abaqus。
- 检查两套文件均生成，并目视比较代表性工况。
