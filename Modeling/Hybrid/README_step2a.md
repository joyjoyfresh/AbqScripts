# TSSI Step-2a：二维框架-土相互作用(SSI) 耦合机制验证

TSSI 路线第二步(a)。在 step1(固定基础框架已验)上，验证【新增 SSI 耦合机制】：
框架-土 Tie 耦合、地震波透过土体输入、周期侧边(1D 剪切)、SSI vs 固定基础对比。
**刻意用平层均质土 + 竖向输入隔离 SSI 机制**；坡面几何+斜入射(Multi 已验)留 step2b。

## 文件

| 文件 | 作用 |
|------|------|
| `frame_ssi_v1.py`    | 建 `freefield`(仅土) + `ssi`(框架坐土顶 Tie) 两模型并提交 |
| `postproc_ssi_v1.py` | 读两 ODB：场地放大/基频、SSI 周期延长、结构响应对比 |

## 运行

```bash
# 工作目录放一条加速度 .txt
abaqus cae noGUI=frame_ssi_v1.py        # 建+提交 freefield + ssi（各约 4 分钟）
abaqus cae noGUI=postproc_ssi_v1.py     # 后处理对比
```

## 边界方案（平层 SSI 标准做法）

- **基底**：刚性输入 `AccelerationBC` 水平加速度(沿用 step1 已验机制) + 竖向 U2=0
- **侧边**：周期 Equation(左右同高 U1/U2 相等) → 土块纯 1D 剪切
- **地表**：自由；**框架基底** Tie 到土体地表(`tieRotations=OFF` 柱脚铰接，整体摇摆经多柱差动竖向捕捉)

> 注：这里用**周期侧边+刚性基底**(平层 SSI 标准)，不是 Multi 的粘弹性吸收边界——
> 吸收边界是坡面**散射**才需要的，留 step2b 接 Multi 引擎时再上。

## 实跑验证结果（2026-06-30，Abaqus 2021，ricker_wavelet_4Hz，5层3跨，土 Vs=300/H=30m）

全过：

| 验证项 | 结果 | 判据 | 状态 |
|--------|------|------|------|
| 场地自由场 | 地表放大 1.83×，主频 **2.50Hz = Vs/4H 精确** | f≈f0 | ✅ |
| SSI 周期延长 | T_ssi=0.667s vs T_fixed=0.500s，比值 1.33 | >1 | ✅ |
| SSI 结构响应 | 基底剪力 2.02e5N、漂移 0.0020、顶层放大 1.68× | 合理 | ✅ |

物理自洽(对比 step1 固定基础)：周期延长、漂移增大(软系统)、基底剪力略降、顶层放大略降——全是 SSI 正确方向。

**踩坑**：`model.Tie` 在 Abaqus 2021 用旧关键字 `master=`/`slave=`(非 `main`/`secondary`)。

## 当前版本边界（v1）

- **平层均质土 + 竖向输入**：隔离 SSI 机制；坡面+分层+斜入射留 step2b。
- **柱脚 Tie 铰接**(tieRotations=OFF)：整体摇摆经多柱差动竖向捕捉；要柱脚抗弯需加基础底板。
- **基础运动用土体地表中心节点近似**(框架居中、周期侧边→地表近 1D 均匀，x 错位影响小)。
- **结构弹性**：沿用 step1，CDP 留 step3。
