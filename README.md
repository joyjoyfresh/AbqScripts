# Abaqus Scripts: 斜坡地形对地震动分布影响研究

本项目是一组面向 Abaqus 的 Python 脚本，主要用于构建二维平面应变斜坡场地模型，施加斜入射地震动（支持 SV 波等）以及粘弹性人工边界（VAB），并在计算完成后进行后处理（包括 PGA 提取、节点特定观测点结果输出、网格收敛性分析及结果数据可视化）。

## 项目结构

```
Scripts/
├─ Batch/                 # 批处理工具（快速选择执行脚本、路径查看等）
├─ Modeling/
│  ├─ Single/             # 单模型主流程脚本
│  │                      # 推荐使用最新版本：VAB_oblique_noGUI_v13.py
│  └─ Multi/              # 多模型相关脚本
├─ Nodes/                 # 节点与坐标读取、节点集创建操作工具
├─ Postprocess/           # ODB 后处理与结果分析
│                         # 功能：PGA 分布统计、观测点提取、网格收敛分析
└─ Wave/
   ├─ Seismic/            # 地震波信号预处理
   │                      # 低通滤波、调幅、傅里叶谱、反应谱绘制
   └─ Impulse/            # 脉冲/Ricker 波生成工具
```

## 工作流程

推荐按照以下数据流和业务逻辑顺序运行各项脚本：

```
地震波预处理 → 建模与计算 → PGA 提取 → 观测点提取 → 结果分析与可视化
   第一步        第二步       第三步      第四步        第五步
```

---

## 详细步骤

### 第一步：地震波预处理及调幅分析

**脚本**：`Wave/Seismic/scale_and_plot_v3.py`

**功能**：
- 扫描目录下的原始 `.txt` 时程文件
- 执行基于信号频率要求的低通滤波处理（默认 15 Hz）
- 按目标 PGA 缩放原时程序列并输出 `_scaled.txt` 处理波形
- 生成频域分析图表：
  - 原始加速度时刻图
  - 傅里叶振幅谱（FFT）
  - 5% 阻尼弹性加速度反应谱
  - 汇总图（保存为 PNG，路径 `Scaled/`）

---

### 第二步：建模与批量有限元计算

**脚本**：`Modeling/Single/VAB_oblique_noGUI_v13.py`（最新版本）

**功能**：
- 基于配置构建多工况（坡高、坡角、几何与物理参数）
- 支持地震波斜角度射入
- 使用等效黏弹性理论处理基岩层及自由边界条件
- 自动拷贝修改模型文件并创建计算任务
- 全过程无需启动 Abaqus GUI

**运行方式**：
```bash
abaqus cae noGUI=Modeling/Single/VAB_oblique_noGUI_v13.py
```

---

### 第三步：ODB 后处理与 PGA 提取

**脚本**：`Postprocess/Postprocess_PGA_v6.py`

**功能**：
- 高效提取地表目标面坐标（坡顶、斜坡面、坡脚）
- 提取最大垂直/水平向加速度作为 PGA 值
- 基于斜坡高度处理相对无量纲坐标 `x/h`
- Bucket 平滑降采样保留代表计算节点
- 输出详细 `.csv` 文件（`PGA_job-XXX.csv`），包含：
  - 绝对 PGA 值
  - 峰值对应帧与时刻

---

### 第四步：节点观测结果提取（可选）

**脚本**：`Postprocess/Extract_OBS_v1.py`

**功能**：
- 从已计算的 ODB 中独立提取宏观观测点数据
- 提取位置：U（坡顶）、M（坡中）、D（坡脚）
- 输出内容：观测点对应的场变量
- 用途：定制时程与轨迹分析、数据交叉核对

---

### 第五步：分析与可视化

#### 5.1 PGA 分布分析

**脚本**：`Postprocess/Distribution_PGA_v5.py`

**功能**：
- 绘制地表空间 PGA 分布曲线
- 支持多输入波情况的对比展示
- 计算均值曲线（以 `x/h` 为尺度）
- 支持按入射角添加自定义标题和分量信息

#### 5.2 网格收敛性评价

**脚本**：`Postprocess/Mesh_Convergence_v5.py`

**功能**：
- 针对不同网格细分密度进行收敛性比照
- 指定精度参考基准（例如 `mesh_size=1`）
- 快速计算网格步过大带来的误差极值
- 输出：误差分布曲线与统计图表，支持模型选取决策

## 常见问题

### 脚本无法找到文件

**排查要点**：
- 确保执行脚本所在目录与生成的 ODB 文件位置一致
- 检查 TXT 波源文件是否位于脚本寻找的路径
- 验证终端上下文中的 `__file__` 和基础层路径是否正确对应

### 建议：使用绝对路径或在脚本执行前确认当前工作目录

## 输出档案要求

当数据用于产出报告或文献引用时，需要明确归档以下信息：

1. **脚本模块版本与更新时间**
   - 具体使用的脚本尾号（版本号）
   - 最后更新时间

2. **计算参数**
   - 目标地震波参数
   - 缩放策略
   - 最高求解波动频率

3. **网格建议阈值**
   - 基岩面最大划分尺寸建议：`mesh_size ≈ Vs / (10 × f_max)`
   - 其中 `Vs` 为剪切波速度，`f_max` 为最高频率
