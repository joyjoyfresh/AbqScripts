# Abaqus Scripts: 斜坡地形对地震动分布影响研究

本项目是一组面向 Abaqus 的 Python 脚本，主要用于构建二维平面应变斜坡场地模型，施加斜入射地震动（支持SV波等）以及粘弹性人工边界（VAB），并在计算完成后进行后处理（包括 PGA 提取、节点特定观测点结果输出、网格收敛性分析及结果数据可视化）。

## 1. 目录结构说明

```text
Scripts/
├─ Batch/                 # 批处理工具（批量/选择执行 Python 脚本、查看路径等系统工具）
├─ Modeling/
│  ├─ Single/             # 单模型主流程脚本（推荐使用最新版本：VAB_oblique_noGUI_v13.py）
│  └─ Multi/              # 多模型相关脚本
├─ Nodes/                 # 独立节点与坐标读取、节点集创建操作工具
├─ Postprocess/           # ODB 后处理与结果分析（PGA 分布统计、观测点提取、网格收敛分析）
└─ Wave/
     ├─ Seismic/          # 地震波信号序列预处理（低通滤波、调幅、傅里叶谱及反应谱绘制）
     └─ Impulse/          # 脉冲/Ricker 波生波工具
```

## 2. 核心工作流与推荐脚本操作顺序

建议根据以下数据流和业务使用逻辑流次序运行各项脚本进行工程计算和展示：

### 第一步：地震波预处理及调幅分析
**工具路径**：`Wave/Seismic/scale_and_plot_v3.py`

**主要功能**：
- 扫描目录下的原始 `.txt` 的时程文件。
- 执行基于信号频率要求的低通滤波处理（默认使用 15Hz）。
- 按照基准目标 PGA (如等比变换至目标 0.30g）对原时程序列缩放计算并输出 `_scaled.txt` 处理后波形。
- 自动进行频域计算输出：分别保存为原始加速度时刻图表、进行快速傅里叶变换的傅里叶振幅谱、基于 5% 阻尼的弹性加速度反应谱和汇总图，统一保存至 `Scaled` 分类保存导出可视化 PNG。

### 第二步：建模与批量有限元计算提交
**工具路径**：`Modeling/Single/VAB_oblique_noGUI_v13.py`（最新一代主建模脚本）

**主要功能**：
- 基于配置（坡高、坡角等斜坡几何与物理参数）及导入缩放处理后的波形构建多工况。
- 支持处理地震波的斜角度射入。使用计算自由场边界的等效黏弹性理论对基岩层及水平自由边界作边界条件进行波输入替换处理。
- 根据各计算文件自动拷贝修改模型文件并创建计算。全程无需启动 Abaqus 主 GUI 页面。

**典型命令行运行方式**：
```bash
abaqus cae noGUI=Modeling/Single/VAB_oblique_noGUI_v13.py
```

### 第三步：ODB 后处理，提取地表目标面 PGA
**工具路径**：`Postprocess/Postprocess_PGA_v6.py`

**主要功能**：
- 可高效提取在 `VAB_oblique_noGUI_v13.py` 定义面中（上侧坡顶，斜坡面，下坡脚）坐标。
- 提取最大垂直/水平向加速度作为提取 PGA ，并自动基于斜坡高度处理出相对无量纲化相对横向坐标`x/h`，通过 Bucket 平滑降采样保留单个代表计算节点进行导出；输出包含各项对应绝对 PGA 及其峰值对应捕获帧与时刻的详细 `.csv`（`PGA_job-XXX.csv`）。

### 第四步：节点观测结果与特定输出提取（按需执行分支）
**工具路径**：`Postprocess/Extract_OBS_v1.py`

**主要功能**：
- 将传统放在主建模的监控点功能剥离抽取并用这个独立工具完成。
- 用于从计算好的 ODB 中，单独抽离 U（坡顶）、M（坡中）、D（坡脚） 等设定的宏观观测点对应的场变量以进行定制时程与轨迹分析并成表供核对。

### 第五步：计算分析与图形学可视化汇总

#### 分析一：提取分布图分析 (`Postprocess/Distribution_PGA_v5.py`)
主要加载以上后处理 CSV 文件结果绘制地表处空间 PGA 分布情况，能够在一个图形系中展示多输入波情况并计算均值曲线（通过 `x/h` 为尺度），同时也支持按照输入入射角添加特定标题和分量。

#### 分析二：网格收敛性评价控制 (`Postprocess/Mesh_Convergence_v5.py`)
专门负责针对不同输入细分密度的网格进行横向相对性比照差异误差和计算收敛：将指定基准（例如 `mesh_size=1`）的最细尺度设成精度参考面计算基准数据差，快速计算由于网格步过大带来的误差极值进行图表统计与分布差异曲线输出评测模型选取策略。

## 3. 问题排查与常用系统脚本规范
- `Batch` 文件夹提供了纯原生 Python 进行快速执行选择的操作：可以直接交互执行 `Choose_runPython.bat` 切换任意功能。
- （常见无法运行和索引排查）：在 `VAB_` 与各后处理文件，请确保执行基准与计算产生的 ODB 以及被寻找 TXT 波源文件，均在终端上下文的预期 `__file__` 及所在基底层路径相同。
- 使用 `Batch/Auto_runPython.bat` 进行无人值守的多个纯脚本按目录层级顺序迭代加载。

## 4. 特别说明与扩展记录要求
