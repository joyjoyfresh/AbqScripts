## 2026-07-31 审稿意见要点（对修订版，判决 Major Revision）

- A 类（致命）：①O2/O3 工况的坡高与地层拓扑不在代理输入向量中，"适用域拒识"在特征空间不可实现；②全部预注册假设与闸门无量化阈值；③真实波闭环带限不一致（重建 0.5—10 Hz vs 直接 FEM 全带），PGV 系统性偏差；④波型/入射角施加/边界/阻尼模型未声明；⑤无算力估算，30 天表日均约 7 次求解不可行。
