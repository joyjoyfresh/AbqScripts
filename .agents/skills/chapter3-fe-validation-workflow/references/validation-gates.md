# 第三章验证门槛速查

本文件只提供执行速查。正式工况数量、初始阈值和章节映射以 `docs/计划文档/第三章数值模型与可信性验证实施计划.md` 为唯一来源。

## 证据等级

| 等级 | 回答的问题 | 示例 | 是否可单独支撑方法有效性 |
| --- | --- | --- | --- |
| L0 流程 | 能否运行和产出文件 | U0、py_compile、NPZ manifest | 否 |
| L1 实现 | 是否按配置建立 | 几何、材料、集合、测点、哈希 | 否 |
| L2 解析/独立解 | 可解子问题是否正确 | 半空间解析、层状一维独立解 | 可支撑对应子问题 |
| L3 数值解 | 离散和截断误差是否受控 | 网格、时间、域、单元、能量 | 可支撑数值参数 |
| L4 独立二维 | 复杂散射是否依赖单一方法 | SPECFEM2D；OpenSees仅为部分独立 | 可支撑二维规律 |
| L5 外部/适用性 | 是否与公开或真实证据一致 | Shen矩阵、试验/现场、非线性边界 | 支撑声明范围内的外部结论 |

## QA 合取

正式工况至少分别保存以下状态：

```text
qa_configuration
qa_solver
qa_theory
qa_reflection
qa_mesh
qa_time
qa_domain
qa_energy
qa_external
overall_pass = AND(本任务要求的全部 qa_*)
```

不适用的门槛写 `not_applicable` 并说明原因，不能默认为通过。任何一个强制门槛失败时 `overall_pass=false`。

## 指标最低集合

- 端到端解析：双分量峰值、时程 NRMSE、互相关时滞、目标频带幅值和相位、峰后残差。
- 成层一维：传递函数幅相、主共振频率、峰值、同材退化。
- 数值收敛：空间曲线 L2、AR_max、峰位、主频、竖向转换量；单调时报告 GCI。
- 边界：反射到时、幅值比、频带反射谱、能量比和目标窗污染。
- 独立二维/文献：多测点时程、坡面全曲线、峰值、峰位、主频和数字化不确定度。
- 单元：人工能量比、相对能量残差、网格长宽比和畸变单元。

## 负对照

至少使用故意反射边界、同材人工分层、正负入射镜像和故意粗网格中的适用项。正常模型通过但负对照没有显著恶化时，优先判定指标无效，而不是证明模型稳健。
